# 妙屋英语 · THE STORY & WORD LIBRARY

在线故事背单词产品。四级先行；统一账号、不同考试分类独立授权。手机、平板、电脑使用同一响应式网页。

> **目前为 S0 开发工程，不是正式产品。** 账号、激活码和付费正文的安全服务端功能尚未实现。请勿在此使用真实密码、卡密、客户信息，也不要公开销售。

## 已完成
- GitHub 私有项目初始化；与 Plot & Pinyin 完全隔离。
- Cloudflare Worker 工程配置和 `GET /api/health` 健康检查。
- 公开静态开发占位页；其他 `/api/*` 均返回 HTTP 501，禁止误用假登录。
- 数据库表结构草案：用户、分类、小说、章节、词汇、激活码、分类购买权限、会话、学习记录。
- 产品架构、安全底线及开发里程碑文档。

## 本地开发
安装 Node.js 22+，执行：

```bash
npm install
npm run dev
npm run check
```

当前没有线上 D1 绑定；数据库结构在 `db/001_schema.sql`，不应直接在生产环境迁移。

完整说明见 `docs/ARCHITECTURE.md`、`docs/ROADMAP.md`、`docs/OWNER_CHECKLIST.md`。
