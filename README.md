# 妙屋英语 · THE STORY & WORD LIBRARY

基于已确认 V0.3 原型启动的正式开发工程。四级先行，支持未来六级、考研、雅思等考试分类。

> **当前是开发分支，不可作为真实付费网站使用。** 页面上的模拟激活码、模拟用户和学习数据仍保留原型逻辑。注册、登录、商品兑换、跨设备同步和付费章节保护尚未接入真实后端。

## 已经提交

- `public/index.html`、`public/styles.css`、`public/app.js`：从确认的 V0.3 原型拆分而来，保留页面、封面素材和交互。
- `design/v0.3-original.html`：V0.3 原始单文件备份。
- `src/worker.js`：Cloudflare Worker 入口。仅 `GET /api/health` 可用，其他 API 故意返回 501，防止误以为已有真实身份验证。
- `db/001_schema.sql`：用户、内容、激活码、分类授权、阅读与复习数据的数据库草案。
- `tests/worker.test.mjs`：基础健康检查与默认拒绝未实现 API 的自动化测试。
- `docs/`：架构、开发计划及安全与交付要求。

## 本地运行

需要 Node.js 22+：

```bash
npm install
npm run dev
npm run check
npm test
```

本分支尚未绑定真实 D1 数据库，也没有接入 Cloudflare 生产环境。
