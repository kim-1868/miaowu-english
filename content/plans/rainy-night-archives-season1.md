## 故事承诺与谜题设计

主角 **林予安** 在家族旧书店守夜，收到模仿失踪两年的姐姐 **林予宁** 笔迹的匿名信。信要求她在 **23:47** 前阻止灰色大衣男人借走《海边的第二封信》；男人自称两年前暴雨夜的唯一目击者，却被监控文件的异常访问记录所牵连。

**第一季主谜底**：当年旧书店的寄存账本与街区防汛物资的借用记录被人秘密替换，以掩盖错误的资源调拨。予宁在发现证据后失去与家人的联系，留下跨时间的纸本线索作为自证。匿名信并非超自然预言：它通过旧书店“雨夜延时归还”信箱被延迟投递；23:47 是旧馆门禁每天例行切换的时间。

**人物关系**：予安坚持答案要有证据；予宁不愿把妹妹卷入风险；灰大衣男人原是旧档案馆修复员，既知道真相又害怕承担旧日责任。真正有争议的是当年的记录篡改，而不是单纯制造坏人或超自然反转。

**公平线索**：匿名信纸张水印、右倾笔迹、监控权限变动、旧借阅卡第47号、背页反写日期、封面书脊的雨滴压痕、修复员工作照片、门禁切换日志。每个线索都在揭晓前至少出现一次。

## 内容工作流（不得跳过）

1. 先建立一份 180–240 词的**候选分章节词汇池**，与真实大纲/词频资源逐条校对；不要把所有词都称为“官方四级核心”。
2. 每章完成中文剧情正文，再执行自然化英语词汇嵌入。每次只处理章节允许的新词及少量复现词，不在生硬位置硬插英文。
3. 每章从正文生成词条及语境锚点；校验 word ID 唯一、词形和词性、例句发音、中文释义一致。
4. 建立跨章节“线索连续性表”及“高频词复现矩阵”，避免章节之间逻辑冲突。
5. AI 结构检查后由用户完成原创性/语言/词汇准确度人工复核；**不代替真实人工批准**。
6. 执行 `npm run content:check` 或针对待导入 JSON 的私有检查，在 staging 导入为 draft。审核确认之后才允许受控发布。
7. 小范围试读（含手机夜间模式、发音、章节完成、收藏、剧情回声），问题修复后再决定是否面向付费用户。
