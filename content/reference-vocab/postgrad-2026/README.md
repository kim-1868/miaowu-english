## 状态

**原始资料已保存，结构化完成，但尚未完成逐项词典校对/官方真题交叉验证。**

这是从用户提供的第三方 PDF《考研英语真题词频词汇表》抽取的参考词表，用于：
- 后续考研类别小说词汇选取、分层和复现密度安排

- 标记高频词、补充词、功能词，提供出版台词卡人工审校的参考

**不得将此目录中的音标、中文释义或统计数字未经校对直接替换正式 `words` 数据表；不得把 PDF 声称的词频视为经过本站独立验证的事实。**

## 数据与来源

- 来源：用户上传的 90 页 PDF；源文件签名及 SHA-256 见 `manifest.json`。
- 原文声称统计 46 套英语一/英语二官方真题；本站并未独立复核原始 46 套试卷。
- 6,082 条（正文 5,297；派生/超纲补充 545；基础功能词 240）。
- 正文词按原 PDF 分成 500 极高频、1,000 高频、1,500 中频、2,297 大纲覆盖词。
- 4,966 个词条可抽取数值词频信息，另外 1,116 条注明 46 套真题中未考查。
- 词条中包括短语、习惯搭配（如 `ice cream`、`according to`），不应盲目拆词。
- 原 PDF 末页提到一份更详细的配套 CSV，但**用户尚未提供**；本网的 CSV 是从 PDF 自动整理的，不含 PDF 中不可见的原始列（首见年份、分题型出现次数等）。

## 文件

- `postgrad_2026_vocabulary_source.csv`: **当前 GitHub 仓库中的完整 6,082 条参考词表**，保留 PDF 可识别的词汇、词频、音标、中文释义和原始页码。
- `manifest.json`: 统计、来源及校验信息。
- `source_quality_flags.json`: 从原 PDF 解析时检测的部分释义问题，供后续人工校对，不代表已审核完成。

**文件库中的源资料**：`/开发英语单词学习网站/考研英语词库/` 另存有原版 `考研英语真题词频词汇表.pdf`、结构化 `postgrad_2026_vocabulary_source.jsonl` 和说明文档。原始 PDF 及 JSONL 未提交到 GitHub 仓库；如需复核词义，请使用文件库中的原 PDF。

## 关键字段

`id` 对应原文排名（如 `1`,`S1`,`F1`），`section` 为分类，`phonetic_uk_source`、`definition_zh_source` 均为 PDF 中的原文数据（不等于已审校的本站词卡），`weighted_score`、`raw_count`、`exam_paper_count`、`last_seen_year` 按 PDF 字段保留，未出现的字段为 `null`。
