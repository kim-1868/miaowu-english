# 妙屋英语 WordLetter · V2 批量生产与质量标准

## 原则：故事先行，词库是规划范围，不是写作枷锁

- AI 先交付可读的故事大纲，明确故事承诺、人物目标与损失、每章行动-阻碍-选择-后果-新信息-追读钩子、结局回收；否则返工。
- 每本必须独立有看点，整批不能重复“文件遗失—手机短信—秘密身份—突然反转”的相同剧情模式。
- 目标句有英语词 2–5 个、段落平均约 3–6 次标注作为弹性参考，不应强迫关键对白、反转及情感爆发场景达到密度。
- 英语目标词只从批次锁定 `headword` 候选池中挑选；正文可用自然中文连接。词表未审核的音标和中文词义不得复制到词卡作为权威定稿。
- CET-4 对发布前书架约 35% 重复的目标以**真实已发布、同级词目**计算，30%–40% 为既定范围；其他等级只呈现实测复现率，不擅自套指标。
- 多义/多词性独立审核，沿用相同学习身份前必须确认真实义项对应；绝不因为相同拼写强制复用旧 ID。
- 每章生成后对所用词卡逐项检查，整本最终按真实阅读体验做独立盲审，具体找出注水、无推进、逻辑断裂、人物不合理、结局没有回收。
- AI 打分≥85 分仅是预审参考，不等于专业编辑或读者验收。
- 结构、词汇越界、错误词义、明显错误IPA、复习身份问题及出版权属风险均为必须阻断或进入人工复核的项目。
- 只输出待审候选包，不自动上传、不触碰 D1/用户数据、无需额外 API Key（Codex CLI 登录使用受账户额度限制）。

## V2 已实现 vs 不可过度承诺

已实现：批次选词范围锁定、整批词目初始分配、生成不同题材故事概念、分本剧情预审和限定返工、模型按章写作与审校、整书 AI 读者评议、真实正文词目使用率汇总、断点续跑、互斥锁、本地候选 ZIP、耗时日志与超时保护。

仍需真人/线上校验：全部音标的词典核验、实际文学吸引力、当前线上出版台规则、同义共享学习状态、付款权限/订单与封面版权。自动 QA 是风险筛查，**没有自动赋予可上架状态**。
