# WordLetter 小说生产 Agent / Codex 项目约束

你在「妙屋英语 WordLetter」原创中文小说生成项目中工作，**不是网站发布者**。每次运行请先读取本文件、`PRODUCTION_RULES.md`、`config.json`、`shelf.json`。

## 产品定位
- 以中文原创小说为主体，自然融入英语目标词。按 CET-4/CET-6/考研/雅思等级分类售卖；不要添加新付费类型。
- 剧情因果完整、人物有鲜明差异，不复述具体受版权保护的网文，不换名洗稿。
- 默认 `preview=false`，0 章试读。不要擅自给已有用户更改阅读进度/权益。

## 生产纪律
1. **先策划再写作**：规划原创大纲、核心矛盾、章节转折，后计划实际语境需要的英语义项。
2. **一义一卡**：每张卡只教正文实际出现的一个主要词性和义项；`record` 的 n./v. 等重音不同必须分开。相同拼写不同义项不要强合。
3. **书架复现**：四级新书以目标词目 30%-40% 与已出版四级书架重复（优先 35%）。仅当 `shelf.json` 非空且可靠时才能定量自证；其余等级只如实报告不设35%。
4. **内容质量**：可点词和词卡一致，英语例句自然具体且双语翻译准确；音标采用可信词典逐义项核验、未核验标注待审；常用搭配尽可能 1–3 条且真实可用。
5. **自然嵌词**：正文有词的句子通常 2–5 个目标词，段落平均 3–6 次标注；关键对白可适度少。禁止 `work室`、`meeting上`、`从系统missing` 等机械硬拼。
6. **原创出版格式**：只输出出版台实际 JSON 字段 `version/sourceLabel/book/words/chapters`。每章 `paragraphs` 内 `segments` 必须为 `{text}` 或 `{wordId,surface,gloss}`，`text` 片段不可是空格。章节 ID、词 ID 不冲突。
7. **独立编辑复核**：作者与质量审校是不同阶段。对每章所有使用的词卡逐张提交审校结果，严禁凭“字段非空”宣称“英语质量通过”。
8. **准入闸门**：脚本离线 QA 只说明格式与可检测问题；人工词义、词典音标、版权、当前运营台校验、读者端权限和复习去重均是单独未通过闸门。未经人工批准，输出只能写“待审核”。

## 权限安全
- 绝不能连接、修改、上传或恢复 Cloudflare 生产 D1；不能执行 `wrangler d1 execute` 或触碰用户密码、订单、兑换码、激活记录。
- 不调用任何自动发布/网站部署命令。只在**当前新书项目子文件夹内**创建与更新文件。
- `shelf.json` 是某次已出版书架的匿名词汇快照，不是完整实时词典、不是官方考试词表；不展示书籍付费章节正文，不引入真实用户信息。
- 所有 AI 创作/审核结论应如实标注“待人工复核”，无证据不宣称已审核完毕。
