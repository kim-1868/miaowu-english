# 妙屋英语小说 Agent V1.1 · 故事先行更新说明

## 为什么更新

当前 AI 小说最容易“长却无趣”：每章只有对话、讨论、找资料，没有人物决策与真实代价。单纯提高词卡质量无法修复故事本身。

## 已做改变

1. 先生成完整剧情设定和每章因果卡，明确钩子、目标、阻力、决定、后果、新信息、逻辑承接、结局回收。
2. 独立故事主编在生成词卡前审稿，逐章给证据并评分。85 分是暂定 AI 筛查阈值，不证明真人会喜欢。
3. 遇到结构错误或 P0/P1 剧情漏洞，最多自动重修两轮；仍不通过就停下，保留修改前的文件。
4. 通过剧情关卡后才安排 CET4/CET6/考研/雅思词库，遵循原有词卡质量标准。
5. 原 V1 书籍继续按原流程，不自动迁移。

## 当前首本测试不要操作

你 Mac 上《雾中第七封信》正运行 V1。**不要中途解压本新版覆盖原文件夹，也不要同时运行两版**。等待测试完成后，再将新版独立解压测试新书。如果网络中断，可继续使用原 V1 断点续跑。
