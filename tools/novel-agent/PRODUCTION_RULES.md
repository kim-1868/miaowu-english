# 妙屋英语 WordLetter｜小说生成与词卡质量标准 V1.0

> 生效日期：2026-11-06（P5 内容审核经验沉淀）  
> 用途：后续 CET-4、CET-6、考研、雅思小说的策划、生成、编辑、词卡审核、导入前预检。  
> 状态：**内容生产规范**；不代表网站已上线自动拦截，也不授权直接修改生产数据库。

## 0. 为什么升级规范：P5 审核事实与边界

本次规范依据 2026-11-06 生产 D1 **本地备份快照**及其离线内容审核包，总范围为已发布 23 本小说、192 章、2,206 张被已发布章节使用的词卡、6,114 条章节词卡关联。发现：

- 跨书同“英文词目＋词性＋中文释义”的精确匹配候选 **384 组**，对应 **1,056 张额外词卡**；候选不等于确认重复学习，更不可直接删 ID。
- **1,051 张**词卡的 `collocations_json` 为 `[]`；字段非空不代表有真实搭配。
- **179 张**词卡词性字段含混合标注（如 `n./v.`）；并非全部错误，但同词性不同读音/义项必须拆开审核。
- 初轮规则发现 **72 条模板式例句候选**，后一轮采用更严格的正则仅命中 30 条，统计口径不同，不作相加。
- 经具体语境确认或列为高置信候选的案例包括 `leak`（漏水误释“泄露”）、`power`（电力误释“权力”）、`sign`（名词标识误列动词）、`record`（名词/动词混写与重音）、`promotion`（推广场景误用晋升例句）、`work室`（生硬混排）。
- 词卡音标/例句字段未发现空字符串，**但没有完成全量权威发音及释义语义终审**。

以上是规范产生的原因，不是宣称所有现有词卡已被逐张人工核验。

## 1. 不可妥协的产品定位

**中文小说为主体，穿插符合情节的英文目标词，以轻阅读方式学习英语。** 优先保证故事好读、人物行为合理、英语含义准确；不能为词频、覆盖率或自动校验通过牺牲质量。不得以既有受版权保护小说为直接底稿进行换名改写；使用独立人物、冲突、世界观和原创情节。不得未经许可引用第三方封面或受保护原文。

网站面向四级、六级、考研、雅思分级**按分类售卖**；小说题材标签可以在运营后台维护，但不作为前台新的付费类别。新小说默认**免费试读章节数为 0**，仅有明确任务要求并经确认时才能例外。已有购买权益、阅读进度、词卡记录不因内容更新而清空。

## 2. 必须采用的生产流水线（不得跳步）

| 阶段 | 操作 | 必须产出 | 未通过时 |
|---|---|---|---|
| 01 立项 | 确定等级、题材、目标读者、人物冲突与核心悬念，和既有作品区分 | 一页原创剧情提案、预期章节结构 | 剧情重复或只靠套路堆砌则重做 |
| 02 词库规划 | 读取**已出版**同等级去重词库，选“要引入的新词”和“值得复现的旧词”；标记词源核验状态 | 每书候选目标词表：headword、POS、sense、释义、等级来源、跨书状态 | 未提供词源不得宣称“已核验考试词” |
| 03 义项定稿 | 逐词确定正文实际义项与词性；多义词列不同 `sense_key`；读音按所选义项复核 | 按义项去重的词卡草案 | 一卡装入多种不相干义项则拆分 |
| 04 剧情写作 | 按章完成中文小说、自然嵌入目标词；允许删去不适合情节的词 | 完整正文，标记词出现的位置 | 发现“work室”等机械混排即改写 |
| 05 语言审核 | 对照原句逐卡检查中文释义、POS、IPA、英文例句和中文译文、常用搭配 | 词卡 QA 明细、修改日志 | 词义不符、错误词性或不可靠读音禁止上架 |
| 06 覆盖审核 | 再算全书去重覆盖、新词与复现、章节密度、跨书重复、内容长度 | 统计报告及不达标原因 | 优先自然改写，不为数字硬塞词 |
| 07 包装与预检 | 严格遵照**当前出版台真实导入契约与校验器**输出 JSON；检查 IDs、空格片段、段落/词卡引用、权限与封面 | 完整导入包＋预检通过记录＋封面＋标签 | 格式有错误先修再发布 |
| 08 审批上架 | 人工复核错误清单与剧情；在隔离环境/后台预览，确认后上架 | 审核结论、版本与可回滚留痕 | 质量未达标只保留草稿 |

**职责区分：** 生成 Agent 负责原创创作和完整数据交付；审校 Agent 负责逐卡 QA 与修改建议；上架操作者确认审核结果。技术结构检查≠英语质量检查≠读者端回归。

## 3. 词汇覆盖与重复率的硬规则

### 3.1 CET-4 新书（沿用已确认的优先标准）

- 新书跨书重复率：**30%–40%，优先 35%**；新增已出版书架尚未覆盖的不同词目应占 **60%–70%**。只适用于**新书相对出版前书架**，不是全书架历史冗余率。
- `N`＝本书全部章节使用的、经归一/审校的独立目标词目（同书出现多次只算一次）；`R`＝其中已在同等级**已出版**书架出现的独立词目；`A=N-R`；重复率=`R/N`，新增率=`A/N`。
- 与其他书比较用**统一大小写、归一词形/必要时具体义项**，绝不能只比各书 `word_id`。对不同义项分开标注并解释统计口径。
- 目标词源分为“权威来源已核验 / 参考词表候选 / 待核验”，**同时**报告候选覆盖和已核验覆盖。长期规划的“约 4,500 词”不是已认证的官方精确数量。
- 高于 40% 或低于 30% 必须给出剧情和教育目的说明或返工，不可机械制造新词；后期覆盖达到新阶段后按已确认的滚动规则另行调整。

### 3.2 其他等级

- CET-6、考研、雅思沿用相同去重逻辑与质量门槛，但**不擅自套用四级的 35% 数值**；如未制定分级重复目标，先报告真实值，不以“达标”名义强行改写。

### 3.3 同书自然复现和密度

- 核心目标词优先跨不同章节或场景自然复现**约 3–6 次**（编辑参考，不是每个词强制次数）；避免相邻句机械复制。
- 沿用已确认的中英嵌入密度方向：**有目标词的句子通常 2–5 个目标英文词，段落平均约 3–6 次标注**。对短对白、关键悬念、文学性情节允许适度少于目标；以读者理解及自然性优先。
- 同时输出两种指标：**不同目标词目数**（覆盖）和**正文词标注出现次数**（频次）；严禁以出现次数冒充去重覆盖。

## 4. “一义一卡”与读者已有学习记录

- 同一英语词目、同一词性、同一真实教学义项，应尽可能复用已有审核过的学习身份 `sense_id`（或项目现有兼容逻辑识别键）；小说 A 标记「记得」后，小说 B 该义项不再作为未学新卡强制首次学习。
- 小说 B 仍可出现相同英文单词和不同剧情原句，用户**主动**点词可看到释义、发音和原句，也可自愿复习；不能无意义地加一张藏书票、增加已学数量。
- 同形不同义、不同词性或发音不同必须明确分义：`record`（n. 记录 / v. 录制）、`sign`（n. 标志 / v. 签署）、`power`（n. 电力 / n. 权力）。混合 POS 不能直接把全部义项放进同一学习身份。
- 现有跨书旧卡的 `word_id` 与历史 `user_words`、`review_events`、`reading_progress` 均不能在内容生成时被强行重写。新旧义项映射须可追溯、可回滚、经用户学习状态测试。
- 精确文字相同只是**合并候选**，不是语义已审核证明；遇到含糊释义进入待审，不自动合并。

## 5. 词卡质量逐项验收标准

| 项目 | 合格标准 | 必须阻断的错误 |
|---|---|---|
| headword / POS | 与正文词形、词性一致；变形词有正确 lemma | 正文作名词却教作动词；错误词性 |
| sense 与中文释义 | **只教当前情景实际所用的核心义项**；可补扩展义但不得混淆主释义 | “屋顶漏水”释为“泄密”；“切电源”释为“权力” |
| 音标与发音 | IPA 采用可信词典逐义项复核；英美差异如实记录；重音、元音、n/v 重音差异准确；系统朗读需能读对 | 生造音标、重音错位、不同读音盲目复用 |
| example_en / example_zh | 英语句子**自然、语法正确，体现当前义项**；中文翻译忠实不漏信息 | 推广词义配“升职”例句；例句与译文不符 |
| collocations | 每个适用的核心义项**优先提供 1–3 条真实常用搭配**，有中文说明；确实不适用时需标记说明 | 用空 `[]` 冒充已审核；生造搭配、把整句当搭配 |
| 上下文嵌入 | 读起来像流畅中文小说，词汇自然承担信息、动作或情绪 | `work室`、`meeting上` 等明显硬拼/重复；为凑词改变意思 |
| 同书复现 | 同词多次出现应切合不同情节 | 连续堆砌、复制相同段落凑次数 |
| 分级来源 | 词汇等级有可追溯来源和审校状态；不虚称官方资格 | 参考词频表自动等同官方等级词库 |
| 版权与原创 | 独立原创情节和角色，封面有合法使用权 | 换名洗稿、未经许可复用作品素材 |

不得根据“字段非空”认定质量合格。尤其 JSON 字符串 `[]` 代表**零条搭配**。

## 6. 不允许复发的案例库（反例 → 正解）

| 语境 | 禁止做法 | 正确生产约束 |
|---|---|---|
| “屋顶开始 leak” | v. 泄露；例句讲泄露文件 | v. 漏水／渗漏；例句如 *The roof began to leak after the storm.* |
| “切断附近 power” | n. 权力 | n. 电力／电源；例句如 *They turned off the power before repairs.* |
| “门口的 sign” | v. 签署 | n. 标牌／标志，选对应的名词发音和例句 |
| “保存一份 record” | n./v. 混成一义、统一读音 | 当前为 n. 记录；若出现动词另建动词义项并校对重音 |
| “以旧身份做 promotion” | 词义推广，却用职位晋升作例句 | 用营销推广情境例句，另义另卡 |
| “一间 work 室” | 英文词 + 中文固定词缀硬拼 | “工作室”作为中文使用，或改整句为自然可嵌英文的表达，不强留 work |
| “讨论 meeting 后做决定” | 万能模板替换单词 | 结合小说人物与情境写真实英语例句，并提供准确译文 |
| `missing` 放在“名单从系统 missing” | 中文句式生硬模仿英文语法 | 改为“共享系统里那份名单突然不见了”；需要教 missing 则另造自然句 |

**例句可原创，不必逐字照搬小说。** 但它必须切合词卡主义项，且不像“为了塞这个词临时拼出”的无意义句子。中英正文也要确保中文语法自然。

## 7. 出版前硬阻断与分级质量门槛

### P0 / 必须 0 项才准发布

- 主释义与故事实际用法冲突；词性错配；错误词形或明显错误 IPA/重音；例句教学义项错误；英文例句或中文译文明显失真。
- 章内 `word_id` 不存在、章节/书籍关联损坏、英文表面形式与词卡不符；目标词无法正常点击或被错误授权展示。
- 新书将原有已审相同义项建立第二张强制首次学习卡（或无说明地更改用户学习身份）；跨书不同义误合并。
- 发布包含只有空格的 `segments: [{"text":" "}]`、缺少必填字段、章节 ID 冲突等无法通过真实导入校验的内容。
- 非原创或版权风险未处理、正式权限或付费边界未通过。

### P1 / 审校后才能发布

- 重要词卡搭配列表为空且未标不适用原因；英美音标未核实；泛泛的模板化例句；中英嵌入多处机械硬拼。
- 四级目标词跨书重复率不在 30–40%，又没有审核通过的解释；未注明词汇等级来源。
- 主要人物行为、时间线、线索因果不成立或多章节重复注水。

### P2 / 可以优化但需留记录

- 次要修辞润色、可读性细节、少量非重点词自然复现差异；封面/标签优化不影响真实词义与阅读权限的项。

**验收采用“自动发现风险＋逐条人工审定”两段式：** 结构/重复/空数组可机器扫，词义、自然度、发音、原创性必须由审校方给出可追溯结论。P0 不允许靠平均分抵消。

## 8. 生成 Agent 应交付的完整文件包

一次新书完成后，必须在**一次交付**中包含：

1. `故事梗概与分章大纲.md`：人物设定、核心冲突、时间线、每章转折、独创性检查要点。
2. `候选词与义项台账.csv`：`headword,lemma,pos,sense_key,meaning_zh,grade,source_status,is_new_to_published_shelf,planned_chapters,ipa_uk,ipa_us,collocations,qa_status`。
3. `完整小说阅读稿.md`：全章、自然嵌入英语，不只给样章。
4. `最终词卡审校表.csv`：`word_id,headword,pos,sense_key,meaning_zh,ipa_uk,ipa_us,example_en,example_zh,collocations,book_id,chapter_ids,qa_status,review_note`；注明“机器预检”“人工已审”“待复核”。
5. `出版台导入包.json`：依据**当前网站真实 JSON 契约**生成、通过项目现有 `validatePackage` / 导入预检；不要猜导入结构，不可仅凭 JSON 能解析就宣称可上架。
6. `质量与覆盖报告.md`：书籍等级、章节数、目标独立词数 `N`、旧词 `R`、新词 `A`、跨书重复率、词汇等级核验率、词出现次数、各章密度、空搭配/模板句/混合词性/P0 统计、版权来源与例外说明。
7. `修订日志与上架检查清单.md`：旧值→新值、对应章节/word_id、人工审定、未解决问题、封面与后台标签、默认零免费章节、版本信息。

封面若同步制作，沿用已确认的竖版 3:4、推荐 900×1200、底部英语等级统一、同书人物辨识度与角度变化明显等既有规范。**封面质量不能代替词卡审核**。

## 9. 对既有规范的优先级和上线边界

- 本文件补充语言语境、词卡质量与出版检查要求；有关 CET-4 新书跨书重复率与复习去重，继续以 `docs/CET4_STORY_PRODUCTION_STANDARD.md` 中已确认的具体数据口径为准，冲突时以用户后续最新确认优先。
- 现有生产数据库的问题只通过**审核过的差异变更集＋隔离环境回归＋新备份＋可恢复方案**解决。内容规范不授予任何自动批量改 `words`、`user_words`、订单或权限表的权力。
- 当前运营台发码、上架版本回滚、后台 Cloudflare Access 仍需独立端到端验收；不得将它们标为“已验证通过”。

**合格标准一句话：新书能让读者读完一个好故事、学到准确的同一义项，而且换一本书不会被迫重复学习同一张卡。**
