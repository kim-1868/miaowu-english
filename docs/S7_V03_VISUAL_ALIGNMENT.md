# S7 · V0.3 书架呈现与真实功能对齐

## 已确认的事实
- 用户已验收 S6 第四章目录跳转修复（能打开第4章）。
- 用户多次反馈 **S5/S6 的实际页面与原 V0.3 定稿不一致**；视觉验收不能与功能验收混淆。
- 通过对照 `public/design-reference-v03.html` 的内嵌 `<style>` 与 `public/styles.css`，发现现行 CSS **以完整 V0.3 样式作为相同前缀**，主要可见差异来自真实数据库书卡的内容/结构，尤其单个 QA 书、极长 QA 名称和进度区域技术说明。

## 本次完成的修改
1. 原书架三列节奏恢复。只有四级分类实际书目少于三本时，使用先前确认的 `BOOKS` 内规划作品补足布局；明确标注「筹备中」「未上架 · 不可购买」，按钮禁用。**没有改动数据库，也没有把这些规划书当成已发布小说。**
2. 已发布 D1 书籍继续独立呈现，QA 测试书的封面采用较短的设计用标题「故事试读册」，标明「测试内容 · 不出售」，而实际完整书名、内容描述保留在卡片信息和 DOM 无障碍文本中。正式有作品时仍使用真实书名。
3. `GET /api/books?category=...` 返回真实已发布章节数 `chapter_count`。主页每本书的进度栏展示当前账号 D1 已完成章节数、总已发布章节数和百分比；登录后学习数据刷新时同步更新进度栏，不混用以前的 `VISITED` 演示统计。
4. CSS 仅在原样式结尾追加书名自动换行/截断、规划书封面适当降饱和等兼容规则；原 V0.3 CSS 原文保持完整。
5. 主页「如何使用→开始试读」修复为打开真正的已发布书目，不会再无意进入演示章节。
6. 原阅读器的“朗读本章”切换为从实际 D1 段落取 `segments`，中文 `zh-CN`、标注英文 `en-US` 分段朗读，浏览器 SpeechSynthesis 仍依赖客户端设备语音可用性。
7. 更新首页通知、剧情回声横幅、页脚和账户中已经过期的“剧情回声只是演示”说法；当前已接入真实 D1 的三种练习模式，仍须现实浏览器完整验收。
