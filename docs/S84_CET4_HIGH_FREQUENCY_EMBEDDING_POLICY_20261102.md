# S84｜妙屋英语四级小说高频中英混排规范

2026-11-02，产品所有者明确要求：**大幅度提高小说里的英语词汇出现频次和占比**。本规范替代此前仅要求“每章 6–32 个英文嵌词”的低密度规则。小说题材仍只存内部，不展示在网站书架。

## 新的可衡量标准

以**正文汉字数量**为分母，统计 `[[word]]` 英语词汇嵌入的实际出现次数（**不是去重词数**）。

| 指标 | 目标 / 约束 |
|---|---|
| 日常写作推荐 | 每100个汉字出现2.2–3.6处目标词 |
| 每500汉字的参考范围 | 约11–18处英文嵌词 |
| 自动审查的最低值 | 2.2处/100汉字；不足需返工 |
| 过密保护 | 大于4.3处/100汉字需压缩检查，单段最多5处 |
| 重复出现 | 适合语境的重点词跨段落/章节复现2–4次或更多；不硬凑重复 |
| 用词规范 | 仅使用经过来源校对的 CET4 候选词形，审查词性、语境义和英译自然性 |
| 产品作用 | 词频增加不代表词汇覆盖量或考试学习效果已达标，也不代表可立即销售 |

## 同类表达举例

过往的一章约500汉字只有4处英文词，学生很难产生足够的学习接触频率。提升后约500汉字包含11–18次英语词汇出现。

**不要**为了数字写成“他要 `decision` 一个 `choice`，然后 `confirm` 自己的 `future`”，这同时破坏英语词性和中文叙事。

**应该**让符合语义和词性位置的英语自然融入中文，比如：“她翻到合同末页，终于 `notice` 到那条隐藏条款。她让律师 `confirm`，才决定要不要签字。”重点词出现第二次应尽量推进动作或剧情，而不是无缘无故重复。

## 现有六本小说如何返工

1. 先保留原小说人物、事件、结局，逐章检查词义和可自然替换位置；
2. 如旧稿太短，可以通过合理对话、动作、心理活动扩写剧情，同时插入合适目标词；
3. 优先反复利用故事内自然相关词汇（例如合同、签字、选择、证据、承诺），降低每章新增陌生词的压力；
4. 严禁仅为凑频率，直接将不符合语法的英语代替中文、修改原剧情逻辑或抄袭现有网文；
5. 用以下命令查看每章目标、现有次数与缺口，全部36章合格后再考虑教学审核：
   `node scripts/audit-cet4-word-density.mjs --report`
   需要在 CI 或正式内容验收时强制阻断不足：
   `node scripts/audit-cet4-word-density.mjs --enforce`

S84 首先对《重生后我不再讨好他们》第一章实施了高密度改写：由571汉字中4处英语嵌词，提升至约700汉字中17处，作为后续全文修订的内部校准样本。**其余35章还没有全部完成这项新标准，不得声称六本已全部达标。**

## 《雨夜档案》及后续作品

《雨夜档案》的12章原文、音标和教学审校仍遵循已有内容安全门槛；不能因为频率规则更新而跳过审核、开放其余11章。它已有较高英语词汇频率，是否需要扩写以实际逐章统计为准。
