# S48《雨夜档案》：词卡例句与剧情一致性修订

目标是修复**直接影响学习者理解的词卡错误**，不是修改统计次数。已针对三个内部词表文件完成8项具体修订：

1. **mechanism**：`The box had a simple mechanical mechanism.` 使用不必要的同义重复。改为 `A spring mechanism controlled the box.` 并同步中文译句。
2. **interrupt**：例句为录音被暴雨打断，中文“记录”改成准确的“录音”。
3. **switch**：`The system made a switch at midnight.` 不自然；改成 `The system switched to the backup server at midnight.`，同步中文译句。
4. **register**：`registration register` 容易形成不必要重复；改为 `an entry in a register`，即登记簿中的一项记录。
5. **recording**：原词卡写“三十秒”，而第9章经审订后录音约两分钟；改成 `The recording lasted about two minutes.` 并同步译句。
6. **consent**：`consent to record` 语境含糊，改为 `They obtained her consent before recording the interview.`，同步译句。
7. **cooperate**：搭配 `cooperate with` 没有展示合作对象，改为 `cooperate with investigators`。
8. **duplicate**：`duplicate copy` 有语义冗余，改为 `make a duplicate`。

更新后，正文仍保留12章、188目标候选词、733次出现标注；没有更改英美IPA字段、发布标志、正式数据库、用户学习记录和兑换权限。

S47新增了与真实美式IPA词典绑定的188词候选清单，并将数据分成141个单读音候选和47个多候选词；S48专注词义解释、例句自然度与剧情时间一致性。**8处修订不代表188张词卡或全733处语境的全部人工审校已经完成**，后续需持续按优先级审核并按正式入库流程复核。
