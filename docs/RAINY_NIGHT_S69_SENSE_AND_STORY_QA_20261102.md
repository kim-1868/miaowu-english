# S69｜《雨夜档案》题目词性与剧情证据的再校准（私有稿）

本轮实际修订 9 个原文段落，不只是生成检查表。集中解决四类问题：

1. **negative 在原目标词表中是 n.（摄影底片）**，旧第6章第3段却将其塞进“negative 模式”中当作修饰词，学生会混淆教学词性。现在用真正的胶片底片说明名词含义，再说明数字照片的“模拟负片模式”不提供新像素，原目标题词仍是 `negative`。
2. **recent 必须修饰具体名词。** 第7章第30段旧写“在 recent 的某个时间点”，同时仅凭未经核验的复印件就断言姐姐仍能本人签署。现在改为 `recent 签名记录`，明确签署人及安全状态仍需核查。
3. **transcript/ future/ cooperate/ guilt 的搭配。** 修复“笔录 transcript”重复、“窗外的 future”抽象生硬、“约好 cooperate”缺少恰当动词衔接、以及“承认 guilt”将内疚误当成违法事实的语义误用。
4. **第7–8章剧情与语言因果。** 第7章第4段在已经进入阅览室之后突然回到馆外排队，改为明确回忆早晨；第8章两处 `consequence` 先前被用于“我们应该做什么”的劝告，现用于真正的 **错误记录导致的后果**，避免把行为建议误教为“结果”。

逐条回归测试对原文具体章节与词义验证；第6章`negative`题目仍链接原文，旧S56回归断言已同步更新。校验12章/188词/733锚点/36道未批准练习全部不变，商业放行继续 `BLOCKED`。本轮不直接调用Cloudflare D1、支付或用户账号。
