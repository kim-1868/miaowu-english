# 小说草稿整书重写 409 修复交接（2026-11-09）

## 已定位的两类错误
- BOOK_ALREADY_EXISTS_USE_VERSIONED_REVISION：后台新建接口发现已有相同 books.id。不能改ID重新创建，否则会破坏书籍身份和历史词卡。
- REVISED_PACKAGE_INCOMPATIBLE：草稿修订接口以前要求每章段落数相同，并且每一段的所有旧wordId引用按旧顺序仍在原段。整书重写自然改变段落结构及锚点布局。

## 三本书源稿离线对照
- 最初的便利店原稿每章7段，新稿9段。较新的售卖前深度精修稿对照新稿，便利店9段→9段但原锚点位置改变，校园9段→10段，顾总9段→9段但锚点位置改变。
- 与最新深度精修稿比：三本book.id/category/title、全部chapter.id/number、所有已引用wordId以及原有word卡字段均保持一致。
- 与更早的第一轮原稿对比：仍有3/4/6个原正文曾用wordId未在最终新版出现。实际数据库可能保存任一版本，在线未执行只读核验，不能宣称更新包已兼容任何旧版。

## 修复分支与范围
隔离分支：fix/draft-full-rewrite-safe-20261109，基于feature/v11-preview-environment-20261106，不修改网站部署。
- 只有后端核实不存在任何 reading_progress、review_events、book.publish 历史的未发布草稿，才允许改变段落长度及顺序。
- 即使允许重排，也必须保留整本书所有曾引用wordId。原book.id/category/title、章节数量/ID/顺序、词卡身份及共享词卡元数据冲突保护保持不变。
- 有历史发布/学习记录的书仍然严格保护原锚点。历史检查查询失败就拒绝更新，避免意外覆盖。
- 调整返回错误码，具体区分 PARAGRAPH_SHAPE_CHANGED / ORIGINAL_STUDY_WORD_REMOVED / CHAPTER_ID_OR_ORDER_CHANGED / SHARED_WORD_CARD_CONFLICT 等。
- 新增两项合成回归测试，覆盖空历史的安全改段和删旧词卡拒绝。GitHub该分支没有CI运行，测试尚未正式执行或部署；不能称为线上修复完成。
