# 妙屋英语 V1.1 · P5 跨书审核义项五个学习入口影子联调

状态：网站 A 线；**仅隔离 SQLite 离线联调，不连接生产或 staging D1，不启用线上词义映射**。无需 Agent V2。

## 本批实现

- `src/study-identity.js` 的投影函数新增可选的第五个身份解析参数 `keyForRow`，默认仍是现有 `studyKey`；因此当前 Worker、书架、生词本、快速刷词和剧情回声运行路径完全不变。
- 新增 `scripts/v11-reviewed-sense-shadow-views.mjs`：将 #179 的两张审核义项映射表与当前 V1.1 真实的 `projectStudySenseRows`、`scheduleRecallFeedback` 规则合用，采用同一份账号级已授权的学习记录分别计算：
  - 阅读器：当前可阅读词卡是否已学习、掌握、收藏。
  - 记忆藏书票：按审核义项去重、保留已掌握和收藏。
  - 首页与快速刷词：共用到期词义数量、每义项只生成一张卡。
  - 听音拼写：沿用快速刷词同一到期池、相同义项不再生成第二张卡。
  - 剧情回声：只有已经读完且有权限的小说章节才进入长期到期练习。
- `previewReviewedFeedback` 直接复用网站的真实纯函数间隔复习引擎。模拟翻卡、拼写、情境选择是否正确和下一次应复习时间，**不记录答题事件、不写回数据库**。同词不同词性的选择不会误判正确。

## 防误合并与权限保护

- 模拟默认 **reviewed=false**：即使数据库有 014 两张映射表，旧网站词义身份依然不变；只有隔离测试显式开启 reviewed=true 才能使用审核义项。
- 每次开启审核映射都检查已存储的小说快照 SHA-256 是否仍匹配当前词库与上下文；小说修改则拒绝复用旧审核。
- 一个旧文本 `studyKey` 若还关联未审核第三张词卡，拒绝只映射部分旧卡。
- 多个 canonical 复习计划不一致、显式取消掌握与旧历史掌握状态冲突、显式取消收藏与旧收藏冲突时，拒绝自动选择。
- 只读取当前账号可合法进入的已发布、可见章节；已作废兑换码、未购买分类及其他账号的学习数据不会展示。剧情回声仅从已经读完的有权章节取题。
- 返回仅含审核义项 ID、原词卡 ID、状态与匿名汇总，不输出真实用户信息、订单、验证码、学习原文等。脚本不导出云端访问函数或写入数据库的接口。
