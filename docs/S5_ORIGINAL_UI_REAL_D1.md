2. **真实章节**：原阅读器按书籍目录显示从 D1 获取的章节；后台对非试读章节继续依据登录用户的分类授权判断能否读取正文。
3. **云端阅读进度**：原阅读器右侧显示实际账号学习数据；新增「标记本章读完并同步」按钮，调用 `POST /api/me/progress`，刷新后仍在。
4. **云端单词收藏**：原阅读器中的英文标注弹词卡，保留发音按钮、原剧情、释义、音标、例句、搭配，新增收藏／移除／已掌握动作，调用 `PUT /api/me/words/:id`。
5. **记忆藏书票**：原样式直接读取 `GET /api/me/words`，书签、掌握状态和源文本句子真正存储于 D1，并可跨设备使用。
6. **我的书房**：原布局显示云端累计读完章节、已开始书目、收藏单词、已掌握数量，支持最近阅读。

8. **剧情回声暂时保留为原型**，页面已明确标注演示题库；其成绩和练习策略暂不写入 D1，也不把这些原型词与云端词混为一谈。

原来的 `/live.html` 暂时仍作为技术测试页保留，不是今后主入口。

## 测试数据：一键准备一章带词汇的无害 QA 试读

测试数据库此前已有 `qa-cet4` 和 `qa-cet6` 两本权限测试书目，但原章节只是纯文字，没有可点击英文。新增**仅 staging 可用**的固定接口 `POST /api/staging/seed-wordbook-fixture`，在已有 `qa-cet4` 之下插入一章试读：

- 章节 ID：`qa-cet4-wordbook`
- 书名仍为「【测试书目】四级内容权限验证」。
- 第三章「【测试】点词与云端收藏」；只有安全的非商业样本中文以及单词 `promise`。
- 单词 ID：`qa-word-promise`；包括英文、音标、中文释义、英语例句、中文翻译、两组搭配以及剧情位置。
- 只允许受 reviewer 门禁保护的 staging 使用；重复点击 `INSERT OR IGNORE`，不覆盖既有书目或章节、不改变测试激活码及购买权益。
- 如还未创建 QA 书目，先在 `/reading-test.html` 点「创建测试书目」，然后点新增的「准备云端点词测试章」按钮。
- **这不是正式发布接口**，绝不把《【示例草稿】未寄出的信》这种未审核草稿发布，也不暴露未授权付费正文。

## 给用户的简洁验收流程

1. Cloudflare `miaowu-english-staging` → Deployments，确认当前 S5 GitHub 最新提交 Ready。
2. 回到原主站：`https://miaowu-english-staging.kim10086a.workers.dev/`。刷新浏览器（Mac Command+Shift+R），确认酒红与复古书房设计不变。
3. 使用之前已经成功注册的测试账号登录，探索故事的分类书架应显示 D1 中已发布的 QA 书目，不应出现写死的《玫瑰未落幕》等演示书作为真实商品；《【示例草稿】未寄出的信》仍不应在公开书架出现。
4. 选择四级测试书、免费试读章节，点击「标记本章读完并同步」，刷新后再登录，在「我的书房」确认云端统计和最近阅读书籍已更新。
5. 打开原来的 `/reading-test.html`，点「准备云端点词测试章」（如果找不到 QA 书籍，先点「创建测试书目」）。无需执行 SQL、无需新密钥。
6. 回主站、刷新后打开四级测试书的第 3 章「点词与云端收藏」，点击正文中的 `promise`，在原样式弹出的词卡内点击「♡ 收藏藏书票」。
7. 导航「记忆藏书票」，应看到 `promise`、音标、剧情原句、例句、两组搭配与发音按钮，测试「标记已掌握」；刷新登录后状态仍在。
8. 尝试未授权六级付费章，服务器必须拒绝返回正文。测试流程中的所有密码、管理员密钥和验证码不必发给助手。

## 当前边界

- 已经完成的是**原界面接入真实数据库**。不是说网站已经可以公开正式销售。
- 原型的剧情回声与更复杂的复习算法尚未真正联动 D1，且临时功能测试书只有极少量测试内容。接下来应继续实现基于已读章节真实词汇的剧情填词、情境选择、主动拼写，及完整云端复习历史。
- 尚未实现正式的小说发布/撤回、安全审批、商品支付及完整原创四级课程内容生产。测试书仍然不能作为真正商品出售。
- 本阶段复用现有 D1 `reading_progress` 与 `user_words` 表，**没有新的 SQL 迁移**，也不需要变更 Secrets。
- GitHub CI 通过不代表 Cloudflare 已自动部署；线上验收以实际网站为准。
