# 妙屋英语 CET-4 专项修复与未发布审计（2026-11-10）

## 本轮目标与边界

本轮只优先修复四级词表和四级智能背词兼容；不主动扩大六级、考研、雅思的内容范围。原有小说、激活码、阅读进度、已掌握、用户收藏、D1 正式数据保持不变。所有新增词卡均为**未上线、未自动签核的教学审稿候选**。最终正式发布权属于站长。

## 已写入独立 GitHub 草稿分支的改动

1. `scripts/audit-cet4-source.mjs` / `tests/v11-cet4-source-audit.test.mjs`：只读扫描源 CSV，保留原始音标/词性/释义的未审核状态；输出按首现四级、可信语料频率排序的审稿队列，标记全部异常，禁止自动修复可疑头词或直接公开售卖。
2. `content/lexicon/cet4-priority-draft-batch-20261110.jsonl`：新增 **98 张首次归入四级的词卡草稿**（单一教学义项、IPA、正常词性、原创自然英中例句和可信 COCA 排名）；已有10张 CET4 早期审核样本保留，合计 **108 张四级互不重复的候选词卡**。
3. 新增 **76 组有自然语境的常用搭配**；其余卡没有合适搭配就不展示字段。前端只在反馈后展示审核过的非空搭配，中英文本均做转义。
4. 98 张新卡的词频排名由原始 CSV 得出，并以 SHA256 `4ee8c53b7e0656ae7c4e77331c22fb47f54cee369491d795a9648e637fa29935` 固定单测。COCA/BNC 不宣传成四级真题考频。
5. `db/012_smart_vocab_catalog.sql`、`src/smart-vocab-preflight.js`、`src/smart-vocab-api.js`：支持**经人工审校的、没有可信词频的词纲词**作为最后的 `UNRANKED` 补充，不能填虚构正整数。 `B.C.` 等缩写可在独立审核后以 `abbr.` 词性进入学习，绝不因无频次而阻止3849词的完整覆盖。
6. `src/reading-library.js` 和 `src/study-identity.js`：只有特性双开关和真实权益有效时，审核通过的无频次词卡也能进入藏书票，阅读记录与词义共享规则保持原有保守身份。
7. `src/smart-vocab-card-quality.js` 增加对可选搭配的结构检查；服务端对于 JSON 格式损坏的审核记录不认定为可开放词库。
8. `scripts/build-cet4-approved-staging-package.mjs` / 专项测试：仅对明确 `reviewed=true` 且逐项标记 `ipa_verified=true`、`meaning_reviewed=true`、`example_reviewed=true`、附审核人/审核日期的四级词卡生成**候选预览站 SQL**。默认不允许不足3849词冒充完整库。即使生成 SQL，也始终把学习开关设为关闭，绝不自动执行/部署。

## 安全交付规则

- **108/3849 是候选草稿，不是108张正式发布/人工签核词卡。人工签核仍为 0**；不能为了做快而批量将原词典 IPA、中文大段释义或模板例句填入正式库。
- 先核对已有小说词义和词卡 ID，再决定新卡的共享身份；相同义项不得要求重复学习，不同义项不能被强制合并。
- 发布前要求完整层级词卡审校，真实预览 D1 完整权限/跨设备/复习/收藏流程回归，检查当前正式站 SHA/并行小说修复，站长明确审批。**本轮没有正式数据库或正式站修改。**
- 当前 GitHub PR #206 保留 Draft，自动化测试属于模拟和构建验证，不是预览站真人验收。构建资源与新 UI 已隔离，未批准的智能背词页面不会提前进入正式静态构建。
