## PDF 源文能证明什么

封面为《全国大学英语四、六级考试大纲（2016年修订版）》。PDF 第20页／印刷第15页的词表说明明确写明：共5418个词目，六级词用 ★ 标识，**只列词形，不列词性、不给释义、不注读音**。具体词表在PDF第21–149页（书内第16–144页）。

因此这次能够判定 **单词是否作为独立词目/词形列出，以及在原文是否带六级星标**，不能借此判定词卡的中文释义、语境词性、英美音标、听力发音或教学质量已审定。对于书中同一行并列的派生词形，星标属于该行的词族；例如PDF第24页（印刷19页）列为 `★allocate allocation`，不能因 allocation 不是该行第一个词就误判四级。

## 受影响的商品和学习策略

- 在当前188个学习目标中，**最多只有172个可宣称“2016年四级大纲无星标词形”，不能宣称188个都是四级大纲核心词**。这172词只是字形证据，不表示词义或发音质量已经合格。
- 首发可以选择保留有助悬疑叙事的9个六级单词作为 **“剧情拓展词/六级拓展”**，但其词卡标签须准确；如果要把所有188项都当作四级核心词，则必须先改写对应语境、词卡以及剧情回声题库再复审，不能直接把词形替换后破坏情节。
- 7个非独立词目中，blurred、hidden 等很可能适合作为 **词形变化** 教学，别误将它们包装成7个独立的官方四级词目。
- 不用 PDF 进行音标和词义认证：源书已经明确不提供这两种资料。英美 IPA 仍另行核对可追溯词典；词卡中的语境义、例句、词性、搭配等也需要分别人工审读。
- 完全保留 `draft-`/【测试】内容、生产 D1、后台权益、测试账号和学习数据。本轮 GitHub 只增加审核工具、测试及内部记录，绝不自动改变 `verifiedCET4` 或线上读者可见内容。
