## 开发环境对接
- `scripts/triage-exam-missing-senses.py` 接受完整、SHA-verified 的私人 **7391 原始交付 zip**，输出 6550 词的 POS/中文翻译片段与风险标记，明确 `publisher_approved=false`、`approved_sense_id=null`、`publication_ready=false`。
- `scripts/compile-exam-original-review-drafts.py` 将经过人工编写的私人 TSV 例句与上述 `triage` 对齐；只补建议例句，不改官方 lesson 或旧卡 ID。
- CI 只运行**合成数据**，私人目录、用户账号/消费数据/版权小说和真实用户 ID 不上传公共 GitHub Actions。
