## 给当前用户的下一步

1. 在普通浏览器窗口中使用 **已有测试读者账号**登录妙屋英语。不要新建账号，不要分享密码、Token 或激活码。
2. 在站点地址后打开 `/api/auth/me`，只确认是否含有 `"slug":"cet4"`；分享结果时遮住用户名及其他个人内容。
3. 在同一浏览器地址后打开 `/api/chapters/qa-cet4-paid`：
   - 如果 categories 含 `cet4`：应返回可读 QA 章节及 HTTP 200；
   - 如果不含 `cet4`：应返回 `PURCHASE_REQUIRED`（HTTP 403）且绝不能泄露章节正文。
4. 只报告“CET4 权益：有/无；章节结果：可读/403/错误”，无需上传正文。
5. 如果 `/api/auth/me` 为 `LOGIN_REQUIRED`，先通过真实账号登录页面完成登录；不用给助理密码。
