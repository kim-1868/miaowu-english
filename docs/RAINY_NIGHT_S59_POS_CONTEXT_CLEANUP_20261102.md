# S59：《雨夜档案》英文词性与中文混排：16处高置信修复

时间：2026-11-02。**内部未发布小说**，本轮只修正文实际语言表达，不声称通过完整人工语言编辑，也不导入 D1/放行商业发布。

对 733 处正文标注做句法风险扫描后，发现下列四类问题：

- **动词错放在名词位置：** `contact`（原稿“最早的一次 contact”“contact 方式”等）、`distribute`（“每一次 distribute 物资的记录”）。改为明确的动词+宾语/动词+后置记录关系，不更改目标词本身。
- **形容词当名词单独使用：** `original` 的个别实例缺少中心词（“核对 original”“保存 original”），改为 `original 纸本`、`original 文件`、`original 信件`；`missing` 移除僵硬的重复助词，`accurate` 改为更合适的表语位置。
- **中式英语套用或词性逻辑错误：** `choice` 不再“做错过一个”；`clue` 不再被“引导新的线索”直接修饰。
- **叙事锚点可读性：** `independent` 明确为与当事人无利害关系的核查员。避免含糊“有经验的独立人员”。

本轮 **16处原文替换**，分布于第1、2、3、5、6、7、9、11、12章。可执行回归固定每处原稿语句，原章节12、目标词188、英文锚点733、内部剧情回声题36不变。无第三方素材搬运，无云端操作，全部审校状态依旧未批准。

这不是一次泛泛的“文字变顺”，而是把目标词原本错误的词性和补足中心词/宾语的教学语境一起修正；后续仍须逐条复查更多可能存在的隐性义项、搭配及全文故事合理性。
