# S85 | 妙屋英语超高密度中英混排规范（覆盖 S84）

## 用户已确认的写作标准

- **目标：一句完整的叙述句尽量包含 2–5 个英语目标词，整篇平均每段包含 3–6 个英语词。** 特别短的对话、感叹或独立动作句可以少于2个；不为了数字改坏人设与语法。
- 写作不局限于原《雨夜档案》约188词的审计子集。医院 hospital、凌晨 dawn、财产 property、消息 message 等具有明确含义的日常词同样应是候选。
- 英语出现次数与去重词数分开统计；允许一个单词在多个情节自然重复，鼓励同一情节中的相关高频词复现。
- 英语词尽量替换名词、形容词和简单动词，优先选择中文读者能顺利理解的混排位置；动词注意词性和及物性，不能出现“decision 一个 choice”的硬拼。
- 仍按 CET4 学习类别销售，不在网站展示逆袭、BL、霸总等内部题材标签。

## 自动质检（新规则）

| 项目 | 目标 |

| 有内容的叙事句 | 含 25 个及以上汉字的句子，2–5处英文锚点 |
| 每段平均 | 3–6处英文锚点，单段超过8处需要拆段审查 |
| 参考综合词频 | 每100汉字约6–9处，最低5处，超过12处需人工回调 |

运行 `node scripts/audit-cet4-word-density.mjs --report` 可查看36章的实际词频、段均目标词和长句异常；`--enforce` 不达标会退出失败。注意：**自动数字通过不等于阅读自然、教学准确，也不等于上架许可**。
