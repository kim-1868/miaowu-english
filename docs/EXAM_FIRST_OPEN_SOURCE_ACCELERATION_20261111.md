## 对词卡制作的直接提速方式

| 来源/引擎 | 自动完成的*候选* | 人必须核对/明确签核 |
|---|---|---|
| Owner exam 词表 + 现有 D1 索引 | 去重词头 ID、级别标签与旧稿关联 | 6 个缩写的独立身份、真实书词义锚点 |
| ECDICT | 中文释义、POS、音标原始值 | 字段准确性、义项粒度、字段实际许可链 |
| ipa-dict `en_US.txt` | 美式音标读音数组 | 多读音 1,114 项，英式来源及商用字段审核 |
| Open English WordNet（仅作参考） | 英语义项歧义提示 | CC BY 4.0 合规署名，不能直接复制第三方文本到收费卡 |
| AI 原创内容 | 面向上下文批量提出英文例句+中文译文 | 自然度、词义和语法、避免版权性模仿 |
| OPS Publisher 最终签核 | 经过逐项确认后才生成稳定可用 sense ID | 被签核字段与原旧 ID 映射校验、学习状态回归 |

## 使用规则（绝不偏离用户的三个最终目标）

- **效率顺序**：先处理实际小说中高频/重复出现的旧 1,067 义项 → 6,550 个无历史义项词头的分批原始候选 → 一词多义专项 → 逐本旧书自动配卡及新书 V2 自动匹配。建议审稿批次 100–200 条，异常自动入专门队列。
- **不可**凭 ECDICT 有词义、IPA 有读音就直接批量设置 `teaching_ready=1`；原文中无来源或非自由授权的第三方音频/例句不能继承仓库 MIT 标签。en_UK.txt 来自 GPL-3.0 来源，现阶段**明确不导入**，待确认兼容方案或另选授权来源。
- **原始私人 owner 7391 清单、小说正文、旧卡 ID、内部审核决议均只在私人 Library/工作机运行**，公共 GitHub CI 只能使用公开 fixture；禁止把完整 owner 原文导出到公开 CI artifact。
- 每张正式卡必须有：正确且审核过的义项、词性、英/美音标、自然原创英文例句和中文翻译、来源/商用权利证据、Publisher 审核记录；相同义项跨故事复用，新的含义分开 `sense_id`，旧复习和收藏不丢。
- 后续真正发布必须经 staging D1、真实书籍最新版本、阅读器跨书记忆、异常审核、运营台上传、正式站明确批准的完整验收。不因候选字段覆盖率高，就宣称已售内容全部匹配完成。
