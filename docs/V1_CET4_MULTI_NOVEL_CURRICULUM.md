# 妙屋英语｜四级词库跨小说学习体系（产品方向已确认）

日期：2026-11-01。用户确认方向：**将约4500词的四级词库分配到多部独立原创小说中，保证每部作品可读性，并利用书内与跨书的重复曝光提升学习效果。**

本文件是产品与编辑生产**规划**，不是“官方四级词库已经导入/4500词全部审核”“30本书已经完成”或“看完必定掌握”的声明。不在当前线上测试 D1 自动运行迁移或发布内容。

## 一、区分三种“词量”

1. **分类总词库**：可由权威考试大纲、考试真题词义等合法来源整理、校验并去重的目标词集合。四级先以**4500词为举例规划池**，而非未经核对的官方精确数或已完工词库。所选考试大纲和词项口径（lemma / 派生形式 / 熟词僻义）决定最终数字；需要持续维护 `lexiconVersion`。
2. **每本独立词量**：一本完整12章四级小说大约**200个不同的目标词**（可按剧情在180–220之间浮动），其中有**新引入的词 + 早前小说中已出现的复现词**。
3. **每本总曝光**：正文目标词累计出现约**650–750次**（中心700次），指带词卡 wordId 的正文标注次数，**不是700个新单词**；词卡/剧情回声的独立练习另外统计，不能混算。

## 二、全分类分书建议（可读性优先）

| 阶段 | 每本目标词条 | 首次引入 | 从前面书重现 | 该书正文曝光 | 用途 |
|---|---:|---:|---:|---:|---|
| 第1本试点《雨夜档案》（草稿待审） | 约200 | 约200 | 0 | 约700 | 基础场景词、新叙事词和本书章节内复现 |
| 第2本《玫瑰未落幕》（现有2章demo不可视为成稿） | 约200 | 约150 | 约50 | 约700 | 情感/沟通/判断词，与第一本重叠部分核心词 |
| 第3本起（题材多元化） | 约200 | 平均150 | 平均50 | 约700 | 再引入词，同时使已学词进入新语境 |

若**首本200新词，之后每本150新词**，整套约30本独立完整故事可以在数学上引入约4550个词（200 + 29×150）；达到4500词的最后一本可以只引入约100个新词。**这只是容量测算，不是固定出版30本的承诺。** 正式编辑时会有删词、词形归并、词义重复以及剧情限制，因此要按实际去重覆盖率调整数量、作品长度或书数。

单本高密度建议仍保留每章中文正文约3000–3500汉字、完整故事约36000–42000汉字、每章50–65次自然嵌词；高强度只是试读基准，不能要求每70个字硬塞英语。每本应有完整结局；不为词表扩充把一个故事拆成大量无意义作品。

已“在小说里出现” ≠ 用户已经读过、练过、记住、掌握，不能把4500词曝光转化为4500词学习完成率。

## 三、真实剧情中跨书自然复现

- 同一个 `evidence` 可以在悬疑小说里指证据、在校园故事里表示研究依据、在职场故事里出现在说明材料中。先由编辑审核每次的**实际语境义**，不能只为提高计数生硬引用。
- 先在第一本通过章节间自然复现（高优先级词4–6次/本），再在后一部不同题材故事中出现，才能形成**真正跨书复现**。
- **目标示例**：每书约75个核心词×5次、95个场景词×3次、15个补充词×2次、15个情境氛围词×1次=200个词、705次正文标注。其中第二本及以后的“约50个旧词”是200个词的一部分，**不是在200个新词之外再额外增加50个**。
- 不要求每个词都在每本出现。高频词跨多本复现；低频/专门词由题材触发，既保证多样性也避免厌倦。

## 四、用户账号的长期学习统计

建议分开显示四级分类下：
- **词库覆盖**：被已审核、已发布故事覆盖的词数 / 已锁定的四级分类总词数。
- **已遇见**：用户实际打开含该目标词的章节，能够在后台核验阅读/曝光事件的去重词量。仅打开章节是否计入“已遇见”需谨慎：可先定义为“所在章节已读或实际点击”，避免夸大。
- **已收藏**：个人记忆藏书票去重词数。
- **已练习**：用户完成过剧情回声、词汇快复习等可追溯练习的去重词数。
- **掌握中/已掌握**：依照真实复习结果及间隔安排确定，不能因为阅读一次或点一下就自动认为掌握。

**词卡 ID 跨小说复用**：同一个 lemma/同一经审核的义项在不同故事中复用稳定的 `words.id`。现有结构是 `words` → `chapter_words` → `chapters` → `books.category_id`，个人记录是 `user_words(user_id,word_id)` 和 `review_events`。由此可在保留用户数据的情况下跨书归并相同单词，减少重复词卡。**多义、不同词性要提前定义并审核**：简单按 headword 字符串合并可能把不同义项混成一张不准确的词卡。

未来如需分类级多词库并行（CET4/CET6/考研/雅思）、新旧考试词表版本，可考虑在独立 migration 中增加 `category_vocabulary`（category+word ID、词频层/来源/状态）和书目词汇计划表。**目前仅为数据架构设想，先不修改现有 D1/发布分支。**

## 五、内容生产应变成一个可验收的流水线

1. **确定词源和版本**：获取合法可靠、可审核的考试词汇源，按词形、词性、语境义去重，建立 category 的 source/version/可见范围；不能直接复制未经授权的第三方付费词库。
2. **分层**：按高/中/低频与故事实用性打标签，并记录已在哪些书首次出现、最近一次跨书出现；覆盖率必须来自正式审核词表而不是宣传估计。
3. **先规划题材与自然剧情，再分配词表**：不同小说使用悬疑、情感、校园、职场、旅行、科技等题材，增加不同语义场景，但不要因为词表硬套情节。
4. **写作→统计→人工编辑**：记录每个词在章节、书本、整个类别中的 unique/total/cross-chapter/cross-book 次数；检查错词义、重音/IPA、阅读长度、答题一致性。
5. **逐书发布**：未审核小说保持私有 draft，不因同分类权益就自动公开；经正式编辑、权限测试、库存/售后说明后才能入正式 D1，且不覆盖现有 Rose 2章浏览器演示。
6. **读者指标闭环**：区分分类覆盖、用户实际阅读、收藏、练习、掌握，依据用户行为再调整后续小说词表及重复率。跨书词卡复习应保持同一个账号的进度。
