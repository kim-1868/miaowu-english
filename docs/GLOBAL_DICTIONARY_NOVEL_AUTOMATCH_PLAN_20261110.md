# 妙屋英语 · 全站统一词典与小说自动匹配 V1（2026-11-10）

> **重要修订（2026-11-10）**：本文件 0 节的“一词头一份掌握状态”为较早版本设想，**现已被 B1.3–B1.4 的稳定词义身份设计覆盖**。最终规则是“一词头一张展示主卡，按经审核的 `sense_id` 独立学习/复习/收藏；相同义项跨书共享，不同义项独立”。请以 [跨窗口统一规范](UNIFIED_WORDCARD_FULL_PROJECT_HANDOFF_20261110.md) 和 [B1.3 数据库规范](GLOBAL_DICTIONARY_B13_SENSE_ID_AND_HISTORICAL_CARD_WORKLIST_20261110.md) 为准，严禁按本旧版描述直接合并多义词的学习记录。

## 0. 最新需求决策（覆盖旧的「按词义项拆分独立学习卡」设计）

**一个英文原形 / 词头 = 一张词典式主词卡；主卡可包含多个词性、释义、IPA、例句、搭配。** 同一主词卡只有一份用户收藏、学习状态及复习计划。小说中的具体用法可选高亮主卡内对应释义，但不产生第二张学习卡。不规则词形先查经过审核的词形表；有多个合理词头时禁止静默决定。

支持四级、六级、考研、雅思等所有等级；词典自身为跨等级共享基础设施，用户阅读与复习的授权仍必须按照已购买等级及小说授权验证。

## 1. 用户验收目标

**上传任意等级小说 → 识别英文目标词与词形 → 自动匹配统一词典 → 只审核异常 → 上传封面 → 用户明确确认上架。**

- 后台支持旧版 `version:1` 小说 JSON，仍保留已有 `words[]`、`segments.wordId` 输入；新增预检接口及可选新格式，不能破坏旧导入器。
- 自动识别已标注的学习目标词；另外扫描纯文本英文词作为**非强制建议**，避免普通英文对话、人名造成上架阻塞。
- 经过独立校验的、唯一主词头可自动匹配；不确定的词形（如 `saw`）、多个候选词头、现有重复词头、未审教学内容都列异常，必须人工确认或补词。
- 只审核异常，展示具体章节、原词、建议原形、匹配依据和本句上下文；分类为自动匹配 / 歧义复核 / 词典有词但教学未审核 / 缺词。
- 同一个主词头重复出现只保存一个主词卡 ID；允许本句语境展示不同释义，收藏与复习只有一条逻辑身份。
- 封面确认、内容审核、版本号、上架的主动确认仍保留现有保护；系统**不得**预检时上架或静默修改用户数据。

## 2. 技术分层

1. **基础词典只读索引**：保留来源许可证与版本（ECDICT MIT 等）；以 `dictionary_entry_id` + `normalized_headword` 唯一标识主词卡；来源可缺例句或音标，但必须标记 `dictionary_only`。
2. **教学扩充层**：一张主卡下的词义、词性、英/美音标、自然中英例句、常用搭配与审核标记；已审核后才能作为正式目标学习词发布。不同词性的不同发音不能合并成错误的单音标。
3. **词形索引**：独立 `surface → headword` 多候选映射，记录来源、是否人工审核、同形冲突；先精确原形命中，再检查经过复核的词形；不能用任意 `-s/-ed/-ing` 字符串截取直接承诺自动匹配。
4. **小说映射**：`book/chapter/segment → dictionary_entry_id`，可选上下文义项提示；允许同词多处出现，原有 `chapter_words/words.id` 不得直接覆盖。
5. **兼容桥与学习状态**：维护 `legacy_word_id → dictionary_entry_id`，旧 `user_words/review_events/bookmark/due_at` 不原地删除；预览模拟合并，确定冲突/撤销方案后逐步迁移。以前的 `studyKey(headword,POS,meaning)` 只是历史兼容，不再作为新词卡最终主身份。
6. **发布门禁**：准确记录目标学习词的词卡质量、匹配版本、预览 fingerprint；旧的 `BOOK_ALREADY_EXISTS_USE_VERSIONED_REVISION` 必须走版本化更新，不能绕过已有已学标注保护。

## 3. 开发里程碑

- **A1（本轮立即开始）项目任务入库 + 只读匹配核心**：增加测试覆盖精确词头、可信词形、歧义、缺词、旧标注、未标记英文发现、非英语正文；输出可审计预检 JSON，不写数据库。
- **A2 基础词典索引**：取合法授权开源词典的真实字段与版本，建可构建、可增量重建的只读索引，比较 `ECDICT/endict/english-vocabulary` 来源差异。MIT/BSD 仅代表仓库许可证声明，**外部音频及第三方例句另核上游版权**。
- **A3 运营台预检接入**：增加权限受控的 `/api/ops/import/preflight` 只读端点，先接现有 `words` 库，后切统一词典；提交前得到 matched/review/dictionary_only/missing 四类明细与证据。前端只读展示，不改变现有 `/api/ops/import` 正式行为。
- **A4 自动生成关联候选包**：经确认后将新版匹配结果映射至稿件标准结构；保留历史 ID、章节原文和版本号，未校验词卡不可上架。
- **B1 一词一卡 UI/云端学习状态切换**：在隔离预览 D1 审核新旧用户状态冲突，跨书/跨等级保持购买隔离，共享同词主卡状态。
- **B2 真实用户路径验收**：四级和六级各至少1本小说，真机阅读/夜间、收藏、复习、作废权益、云端同步、409版本修订、回滚及备份。

## 4. 必须遵守的约束

- 现阶段 GitHub **Draft** 分支开发与 GitHub Actions 构建；不合并、不部署正式站、不执行生产 D1 迁移、不触碰用户账本或收费状态。
- Stage A 的「自动匹配成功」只表示唯一规范词条关联且满足匹配证据，**不等于全文教学审校合格**。
- 只读预检不将未标注英文自动变成学习目标，以免误将剧情对话、人名列为必学词。
- 源词典包含脏数据和老旧译法；高价值教学词卡应由独立审稿核对，不得把原字典字段直接标为 `reviewed:true`。
- 2026-11-10 原先四级来源词表3849个、现有130个主词头候选，仅是历史工作进度；统一词典建立后须重新计算跨词典等级覆盖，不将来源词表误作官方考试大纲。
- 公共仓承担 Build/自动测试，独立草稿 PR 审批，避免与小说修订 PR #203 或其他正在发布的变动冲突。
