# 妙屋英语｜阅读复习、进度提示、分类图标与封面 V1.2

## 本轮修复范围

1. **本章复习**：点击正在阅读章节里的「本章复习」，从该已发布、当前账号有权读取的章节 `chapter_words` 获取词卡，不再依赖是否收藏，也不依赖 `reading_progress.completed_at`。同一单词去重，每轮至多8题，允许单词找回；提交答案会写入 `review_events`、更新 `user_words`。不允许凭章节ID读取其他人未购的付费章节。最近章节／自选已读章节／今日到期复习仍保留已读完章节及服务端鉴权条件。
2. **雅思分类图标**：由字符 ✳ 改为 ✥，与四级 ✦、六级 ✧、考研 ❦ 互不相同，但保持同一色系和排版；不增加额外依赖。
3. **阅读进度**：只在服务端成功写入后提示「已同步阅读进度」；失败时不标为成功。滚动时每约30秒至多一次防抖同步；点击下一章或离开阅读页继续保存。当前仍是账号云端 D1 同步，没有独立用户计费或保存期限按钮。具体保存年限以站点运营、数据处理政策和备份策略为准，不承诺永久保留。
4. **封面**：首发《雨夜档案》书架和公开介绍页使用新 `rainy-night-cover-v2.svg`（900×1200矢量，文字与线条可清晰缩放）；原模糊 WebP 保留为旧链接兼容资源，不再作为主图。
5. **运营后台图片上传**：支持选中草稿/已发布小说上传与替换，也支持新小说导入后直接关联封面。管理员客户端按3:4居中裁切、缩至900×1200、WebP优先压缩为≤750KiB，仅接受JPG/PNG/WEBP；由独立 publisher 身份授权、按书籍ID绑定至D1；上传不会修改章节、用户分类权益、账号或学习进度。只公开已发布且所在分类公开的书籍封面。SVG 上传被禁止（静态新封面SVG是已审核的仓库文件）。
6. **图片存储成本**：沿用 D1，无需付费AI接口或额外 R2 账户。每个封面占若干百 KB；大量书籍或访问量增长后可改 R2 和 CDN。D1 免费总存储为5GB，但单库上限500MB，实际使用要看Cloudflare Metrics，不能无条件保证长期不超额。

## 生产部署的顺序与阻断条件

- 当前已经确认生产库 `miaowu-english-prod` 与管理员账户存在。用户数据不可删除/初始化。
- 先备份／记录 D1 Time Travel bookmark，**只在正式 D1 Console 中**执行增量脚本 `db/production/004_book_cover_images.sql` 的 `CREATE TABLE IF NOT EXISTS`。无需重新执行原有001–003，也不要改任何 Cloudflare Secret。
- 执行只读校验：

```sql
SELECT name, type FROM sqlite_master
WHERE name IN ('book_cover_images') ORDER BY name;
```

预期返回 `book_cover_images | table`。
- 只有 GitHub CI 的 S1 checks 和 Production dry-run 均通过并合并到生产特性分支、main 工作流 SHA 重新固定在合并后的审核版本后，用户才执行手动 `deploy-free-preview.yml` 发布。不得把本地开发分支直接误部署。
- 发布完成后检查四项：① 第8章打开后立即本章复习能出题（若已有词卡）且不会获取未购内容；② 首页雅思符号与其他三项不同但统一；③ 读一会儿出现「已同步阅读进度」而不会反复弹窗；④ 《雨夜档案》主封面高清，已授权管理员能够在书籍目录选中它并上传一张新的 JPG/PNG/WEBP。
- 没有执行004迁移时，已发布章节、原有书架和静态SVG仍能正常工作；但封面上传接口会返回明确的数据库未配置提示，不要认为上传成功。

## 后续可选增强

- 如书目规模、访问次数或图片成本明显上升，可迁移封面文件到 R2，使用固定封面URL并继续保留 `cover_key` 的业务引用。
- 已上传的封面无法从D1前端操作中直接物理回滚；建议上线前先保留原稿，并在 Cloudflare Time Travel 记录迁移时点，普通替换无需恢复整个数据库。
