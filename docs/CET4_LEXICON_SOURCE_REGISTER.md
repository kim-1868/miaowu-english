# CET4 词库来源核验与版权边界（2026-11-01）

**大学英语四级 CET4 与全国英语等级考试第四级 PETS-4 完全不同，不可混用。**

## 可靠来源记录

- 大学英语四、六级考试大纲（2016年修订版）官方入口：https://cet.neea.edu.cn/html1/folder/16113/1588-1.htm 。用于核对考试体系、版本、技能要求；不在本仓库镜像版权不明的完整词表。
- 清华大学出版社 2009版大学英语四级考试大纲词汇手册：https://www.tup.tsinghua.edu.cn/booksCenter/book_02952501.html 。其介绍记载旧大学英语教学要求下“约4500词”的历史口径；**出版词义、例句、词表编排不可未经授权复制进商业产品**，且年代较久不能冒称2026最新版官方范围。
- 广州大学历史课程大纲：https://fs.gzhu.edu.cn/info/1087/2076.htm 。参考教学背景，不等于一张最新完整官方必背词单。
- PETS-4 官方大纲 https://pets.neea.edu.cn/res/Home/2507/924b59333f331f8f9ada6e27d82606aa.pdf 属于另一个考试：**严禁用它的附录认证 CET4 词条**。

## 项目实际进度

用户决定“约4500个四级词分到多部小说”；4500目前是**产品规划容量**，不是已核验的现行官方词数。

S16 的真实内部候选池：雨夜档案188头词，玫瑰未落幕演示12头词，10词重叠，去重后**190个候选**。所有词的正式CET4范围、含义、英美音标、词形和例句尚未通过独立审核。词条状态全部保持 pending-source-and-sense-review。

## 正式审核字段和规则

每词应有：明确来源与版本、考试目标适配、语境义项、词性/变形、英美IPA依据、原创例句、搭配及审核人/日期。

- 只可使用许可清晰的词库数据、自行写作的释义与例句、或者可合法引用的事实性词条；不批量复制出版词表、例句及选编结构。
- 跨书重复同一个头词时审查词性和义项，不直接将该用户视为掌握新语境的含义。
- 已有的线上 D1 用户词卡/复习数据不能为了统一 ID 而重写。
- 尚未核验的190个候选不能宣传为“已收录190个官方四级词”；完整4500词在正式来源与版本确认前不得标记完成。

这是内部人工审核说明，不发布到客户站点或自动导入远程 D1。
