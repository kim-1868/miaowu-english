# S3-B2 · 直接编辑章节与词卡（测试后台）

状态：GitHub 开发分支已实现代码；**需要在 Cloudflare 测试 D1 单独运行一次 005 迁移**。未执行时已验收的 S3-B 草稿导入和预览功能仍可正常工作，新的修改操作会安全返回 `EDITOR_REVISION_SCHEMA_REQUIRED`。

## 新增内容

- 在 `/editor.html` 的预览中每章增加「编辑这一章」，支持修改章节标题、免费试读标记、正文段落、段落内部纯文字或「英文标注词 + 中文提示」。
- 词汇列表新增「编辑选中词汇」，支持修改 headword、释义、英美音标、词性、英文例句、译文与常用搭配。
- 不改变书目 ID、章节 ID、章序号与单词 ID。仅允许已导入的未发布草稿修改，**不会修改已发布内容**。
- 使用独立编辑密钥和 reviewer 测试站门禁，所有写请求强制同源。
- 写入前校验文字和引用、请求体限制 170 KB；使用 D1 事务批量更新，正文标注变化会同步重建 `chapter_words` 出现位置和上下文。
- **乐观锁**：页面加载时拿到不可逆版本摘要，保存时服务器检查最新版本；别人修改后旧页面保存会返回 `EDIT_CONFLICT`，避免静默覆盖。
- **历史记录**：保存前旧章节/词卡内容记录在 `editorial_revisions`，可以在后台查看并恢复旧版本；恢复也是一次新修改，会保存恢复前的版本。
- 共享词汇保护：如果一个单词被其他书目、其他已发布章节引用，本后台拒绝直接修改，以免更改另一本小说里的释义与例句。
- 审计日志只存于测试数据库；现在仅支持最多 15 条近期历史预览，正式后台的管理员身份审计、审批发布、撤回尚未实现。

## 唯一需要用户操作的数据库增量迁移

1. Cloudflare → D1 → **miaowu-english-test** → Console，确认当前确实是测试库；先查看 D1 Time Travel 或其他可用恢复点。
2. GitHub 里打开 `db/005_editorial_revisions.sql`，复制全文到 Console → Execute。该迁移只创建新表和索引，不删除/更改已有的用户、小说、章节、词汇或权益。
3. 在 Cloudflare → Workers & Pages → `miaowu-english-staging` → Deployments 确认包含本次 S3-B2 代码的最新 GitHub Build 显示 Ready。
4. 打开 `/editor.html`，使用已设置的 `S3_EDITOR_SECRET` 验证编辑权限（不用再次修改密钥）。
5. 草稿书库点击「预览章节与词汇」，确认新出现章节编辑、词卡编辑入口。

**注意**：原项目的 001–004 曾经由人工执行过，不要为了 005 而重新执行全套历史迁移、清空数据库或更改 Secrets。

## 建议验收

使用之前导入的 **《【示例草稿】未寄出的信》**：

1. 点击「编辑第一章」，把一个普通段落里的中文改动一小处，点击「保存章节修改」。
2. 重新预览，应能看到新句子；英文 hesitate/promise 依然可标注，章节仍是未发布状态。
3. 点「查看历史版本」，应看到修改前原文，可以选择恢复。
4. 编辑 `hesitate` 的中文释义或例句，保存后刷新能看到更新；若词汇被其他书共享会返回明确的共享词汇保护提示。
5. 复制另一个页面同时编辑同一章，较旧页面提交时应报「内容已被修改」，不会覆盖较新内容。
6. 登录普通读者书架，示例草稿仍应不可见。

若提示 `EDITOR_REVISION_SCHEMA_REQUIRED`，通常是 005 没有执行成功；若 `EDIT_CONFLICT`，重新载入草稿后再编辑；请发错误文字/截图，不要发送密码、实际未发表小说全文或激活码。

## 安全限制与后续

这不是正式发布系统；没有成熟的管理员身份记录、内容审批发布、评论协作、复制稿件、R2 图片、自动备份或多设备学习同步。当前只对受 reviewer 密码保护的 **staging** 开放，不能用于真实付费商品运营。GitHub 自动化测试通过不代表远程 Cloudflare D1 已升级，需要用户实际网页验收。
