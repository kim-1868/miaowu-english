# S8 · 本章词汇侧栏与速记卡片

本轮只交付用户最终确认的两个功能：本章词汇侧栏和速记卡片。**不开发正文填词、独立手写识别及复杂词卡扩展**。

## 已开发

- 原 V0.3 设计阅读器右侧增加「本章词汇」面板。通过已存在的、有阅读授权的 `GET /api/chapters/:id/words` 获取并按 word_id 去重。
- 每个词显示英文、中文含义，点击打开已有原版词卡，单独提供浏览器发音按钮；侧栏可折叠。
- 速记卡片按本章顺序显示英文、音标、中文和原句，支持上一张/下一张、记得/不记得；两个判断按钮会在保存成功后跳到下一词。
- 记得：追加 `review_events` 记录，状态不会因一次判断升级为已掌握，计划三天后复习（保留已经掌握的历史状态）。
- 不记得：追加记录，自动将单词 bookmarked=1 并标记 learning，计划一天后复习；通过原有「记忆藏书票」读取。
- `POST /api/me/quick-review` 校验登录、chapter_id、word_id、实际章节词关联、书籍已发布、章节已发布且用户有有效分类权益或章节免费，防止任意猜词记录无权阅读的付费材料。
- 移动端在阅读器工具条增加「词汇」按钮，通过屏幕右侧抽屉查看词卡，支持关闭。保留原 CSS/设计基准，不生成另一个主站页面。
- 同一章节中的重复英文仅展示一张速记卡；切换章节会重置当前面板的前端速记游标。
- 复用现有 D1 表 `user_words` 和 `review_events`，不新增 SQL 迁移或 Secret。
- 词卡知识扩展和正文默写不在本次开发范围。

## 用户实际验收

1. Cloudflare staging 的 GitHub 最新 HEAD Deployments 状态 Ready。
2. 打开 `https://miaowu-english-staging.kim10086a.workers.dev/`，用现有测试账号登录。
3. 打开四级 QA 测试书第四章「真实剧情回声·四词练习」；右侧「本章词汇」应显示 4 个词（contract/evidence/identity/confirm）。可以折叠、展开，点击词条打开现有词卡。
4. 进入「开始速记」，测试「记得」和「不记得」，上一张/下一张；速记自动前进不影响小说正文。
5. 在「记忆藏书票」看到点击「不记得」的单词；重新登录后检查记录仍保留。
6. 手机或窄屏设备在阅读器右上角点「词汇」并关闭抽屉，确认正文不会被永久挤压。
7. 检查未授权的六级付费章节不能通过速记接口绕过权限。
8. 如有错误，只需截图或错误文本，不发送密码、激活码、任何 Secret。
