## 二、三个级别是「标签重合」，不是严格嵌套；共享同一主词头

- 统一主键是标准化词头的 `gdict_<stable hash>`。`exam_levels` 是**多对多标签**，同一词头可同时属于高中/四级/六级/考研；不能以英语等级不同重复造 3 张词卡。
- 同一词头可能有不同义项（如 `record` 名词/动词），稳定学习身份必须为**经过审核的 `sense_id`**；同义项跨书/跨等级只学习一次，新义项独立学习。不能仅按词头或中文释义模糊匹配合并旧学习历史。
- 词源的独立 `cet4/cet6/postgrad` 标签不是法定完整考试清单。必须拿**用户自有四级/六级/考研词表**逐一交叉验证，出具包含/缺失/冲突报告；小说出现但三份词表没覆盖的目标词也进审稿队列。
- 同一个学习者的词义熟悉度、收藏和复习计划跨书共享；不同套餐仍分别控制购买权限，**共享词义不等于共享买书权益**。

## 三、开发唯一主线：四项交付门禁

### P0. 词表去重与真实缺口（当前开始，**不要求再导剩余 388,761 词头**）
1. 以用户上传的四级、六级、考研词表为权威目标集合，和 ECDICT 带标签词头交叉；输出三级原始词量、交集、去重并集、未匹配、词形歧义。**不可用 ECDICT 6,158 分母宣称官方词汇覆盖率**。
2. 从真实现网上架小说由已授权 Publisher **只读导出当前完整 JSON**，以 book ID、published revision SHA、章/段/目标词锚点做不可变对账；旧 23 本 P5 历史样本仅用于加速复核，不直接修改当前正式版。
3. 生成统一工作队列，字段 `headword + exam_levels + source_ids + old_word_ids + book_occurrences + requested_gloss + priority + audit_status`；优先「当前书中出现」和「多书高复现」词，再按 CET4 / CET6 补缺 / POSTGRAD 补缺。不得混淆同义项。

**验收**：三套实际词表差集均可审计；真实小说目标词锚点可映射或明确标记异常；无按级别重复词头；无自称完成未审核词卡。

### P1. 制作可销售统一教学卡（**最大工作量，和 P0/小说 V2 调试并行**）
1. 先从私有 1,150 严格历史义项候选中处理 **493 低冲突项**，再攻克 **657 高冲突项**；两组全部都要核验许可、英美 IPA、词性、义项、自然原创英中例句及旧 ID 身份。一词多义按义项扩充，不能用机器分流直接代替商用审批。
2. 用户原词表中出现而旧稿未使用的四级、六级、考研词义，按优先级扩展，不等全部 40 万词完成；严禁把未经审核第三方音频、释义、例句直接搬成付费卡。对于词头匹配但缺具体义项的项目只能标记待审。
3. 经 OPS 认证 Publisher 对每个义项签核后，才可在测试库生成审核 `sense_id`、设置可教学状态。稳定 ID 不因书籍等级或书名变化；文本修订保留明确版本和旧 ID 到新义项的映射。

**验收**：每个可用卡具备合法内容依据、正确音标、准确义项、原创自然双语例句；语义冲突不会自动合并；测试数据库确实存有已批准义项而不只是候选词头。

### P2. 既有四级/六级/考研小说统一配卡（先受控样本，再整库）
1. 从真实 Publisher 只读导出的**当前线上完整版本**执行旁路 preflight；优先 1 本四级 + 1 本六级 + 1 本考研样本，逐个核对词卡覆盖率、章节锚点、易混词形、原有收藏/已掌握/复习记录。
2. 对同义项映射只关联新 `sense_id`，不随意删除原 `word_id`、不改已售 book ID 或购买权益；跨书学习/收藏共享同义项，不产生重复学习卡。
3. 再分批处理其它真实上线版本，逐本对账 409 版本化修订；一律先在预览站验收，再考虑正式站。

**验收**：目标词位置不丢、章节不变、词义不串、旧学习记录不丢、重复义项跨书不再重复要求学习；正式上架书核验覆盖率以真实导出为依据，未见源的书不得写「已匹配」。

### P3. 新小说上传即自动配卡 + 正式发布验收
1. 保留 V2 **不要求作者提供 `words[]`**；上传小说后自动找已审 `entry_id + sense_id`，结合上下文/目标中文 gloss 选择唯一义项，**不确定时不能猜**，转为人工审核差异清单。
2. 无卡/义项不符/词形多解 → 可生成内容草稿候选，但审核前不上架为可学习词卡；补卡可复用到后续所有小说，不再按书重做。
3. 验证阅读器词卡、英美音标/例句点击、剧情答题、快速刷词与错词复习，同 `user + sense_id` 共享计划；收藏、跨设备、不同等级授权及 409 修订受保护。经过预览站完整端到端证据，才可申请正式站上线。

**验收**：真实新书上传成功、自动绑定有审批证据、异常审核清晰、无重复学习、无线上既有用户数据损坏；正式站须单独批准。

## 四、刻意不做成 P0 阻塞的任务

- **第 2–9 批非考试罕见词头远程导入**：作为 P2 扩充/储备工程可在免费 D1 配额允许时推进，严禁占用核心「审词义 → 小说关联 → 线上验收」人力和主线额度。批次不等于卡数。
- 雅思/托福和 400,183 全量“所有词头均做完高质量商用释义+原创例句”是后续扩展，不列入本期三级考试第一版交付标准。
- 不为来源 ECDICT 未审核就跳过许可审核，也不为了短期速度把不同义项按词面强行归并。

## 五、执行方式与项目内交接约定

- 唯一优先级：**当前小说中的高频词义与旧状态身份 > 四级缺口 > 六级新增 > 考研新增 > 更广泛上游原形索引**。其中四级、六级、考研批次制作可并行；三类共用一张主词典表、按义项审核。
- 代码/CI 继续优先公共仓承担、私人词表与付费小说正文/审稿决议不进入公共 artifact。公有仓只能保存匿名统计、算法、结构和测试夹具。
- 每阶段更新 GitHub / 跨窗口总交接，区分 **离线已实现 / staging D1 真实已验证 / 正式站已发布**，杜绝把模拟测试计为上线。
- 未来所有新等级复用同样一套 `entry_id/sense_id` 体系和审稿发布流，新增标签只影响内容过滤和优先级，不影响已有掌握状态。
