# S57：《雨夜档案》剧情回声自然度审核第二轮（7处语境）

在S56对首批7处重点题干修复之后，继续直接审看另外29道剧情回声候选的**真实中文小说段落**。发现7处“词汇形式虽在原文出现，但句式机械/语义不够清楚”的位置，现已同步回写到未公开小说稿中：

| 章节·词汇 | 修改点 |
|---|---|
| 5·repair | 不再说“修复应记录清洗”，改为每次纸张修复都应留下过程记录，因果更清楚 |
| 6·enlarge | 不再使用“在副本上 enlarge”的中式英语结构，明确先制数字副本，再放大图像局部 |
| 8·routine | “每晚自动投递”是例行操作机制，不是例行检查 |
| 8·confuse | 明确不同计时记录容易让初次查阅者混淆，而非抽象地“困惑读者” |
| 9·statement | 具体指居民个人陈述，与公开账目区别明确 |
| 11·sequence | 依据实际交接顺序排列清单，而不是机械地“按 sequence 排开” |
| 12·relief | “迟来的宽慰”更贴合姐妹重逢的情绪，不制造无解释的“沉重的宽慰”冲突 |

变更只涉及私有第3–12章句子，不更换目标词ID、不删掉标注、不改商用元数据；共36题/12章、188词、733个锚点及正式发布安全门禁的数量和状态必须由CI复查。所有36道题仍是 `EDITORIAL_NOT_APPROVED`，不能因审校文字而自动上线。
