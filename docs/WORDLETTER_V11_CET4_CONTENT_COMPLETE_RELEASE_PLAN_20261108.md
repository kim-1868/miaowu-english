## 三、工作台优先于聊天生产
核心目标**可视化小说工厂**，不是在聊天里一章章写。已知私有离线引擎具备计划/导入/运行单章等能力，但尚无完整工作台与批量连续生成。
- W1 公共：工作台 UI/状态机/任务表/审核反馈/导出操作 + 纯虚构样本 Node/Chromium；禁止实际词库与书稿进入公共仓库。公共 Issue #28。
- W2 私人：连接现有 factory.py 的真实任务 API/进程/文件存储、状态、断点恢复；模型凭证与真书稿留私人。
- W3 私人：真实单本8章连写验收，限制模型预算、每章一次主生成至多一次定向修订；失败停机可续，不得默默无限重试。
- W4 私人：导入三本旧稿只读保留原稿及 ID，审校而不重写；通过工作台续写四本新稿，完成文本和词卡QA。
- W5 私人：输出V42契约的出版 JSON，真实隔离导入/上架/权益测试；需要由有权限运营者确认正式发布。
工作台尚不具备真实连续写作能力，不得把 plan-batch 说成“六本已自动生成”。

## 四、必须通过的统一发布 Gate
**G0 功能冻结**：记录预览站最终 Commit/Release、数据库 schema、变更清单；用户确认功能不再变更，允许 P0 修复。
**G1 内容完成**：七本四级正文完整、各章不空缺，语言/剧情自然，符合适用密度标准；先审三旧稿，后审四新稿；原书及源版本可追溯。
**G2 教学终审**：真实引用词卡核释义/词性/IPA/例句/搭配；逐处语境抽检与风险清理；跨书相同义项复用已有 studyKey，不能重置 words.id/学习记录；分类词库覆盖标识真实可核。
**G3 出版预览**：每书正确原创/授权封面，运营台 V42 真正识别与受控 D1 导入（不能用只读识别代替），测试会员四级权益/无权益、全章节、收藏/已掌握、快速刷词、剧情回声、书房进度、跨书学习、移动端，保留测试日志。
**G4 发版合并**：冻结 V1.1 实际预览改动、核对公共 UI 交付 SHA/私人活动 SHA，只有经过安全 Gate 才落地私人生产构建；公共负责纯合成 CI，私人只运行最小真实业务 Gate。
**G5 正式更新**：备份 D1、上传内容采用增量/有审核的事务、Pages/Workers 正式发布，验证原有书/订单/兑换权限/进度不回退；失败有回滚与后续数据审计。发布状态只有真实成功日志/读者可用证据才标记成功。
