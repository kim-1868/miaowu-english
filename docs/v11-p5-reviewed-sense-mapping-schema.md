# 妙屋英语 V1.1 · P5 独立词义映射表与隔离读写验收

状态：**仅完成离线隔离数据库中的映射存储设计和测试**。不是线上学习逻辑切换，不访问或修改正式 D1，不依赖 Agent V2。

## 设计目标

同一个英语单词可能因小说场景不同，具有不同词性或含义。已确认相同教学义项可统一学习状态；不同义项保持独立。过去发表的 wordId、章节词卡、user_words、review_events、阅读进度以及用户权益都不能被合并或删除。

### 新增数据库 014

- reviewed_sense_groups：人工审校后的义项 ID（reviewed: 前缀），绑定来源快照 SHA-256、审核证据哈希、审核员和日期。
- reviewed_sense_aliases：每个原词卡 word_id 对应一个审核义项及原始 studyKey；一张旧词卡最多归属一个审核义项。对旧 words.id 和主表都有外键保护；支持按审核义项检索。
- 仅通过 CREATE TABLE IF NOT EXISTS 和 CREATE INDEX IF NOT EXISTS 增加独立表，不使用 ALTER/DROP/UPDATE/DELETE 修改任一历史表。

文件：db/014_v11_reviewed_sense_aliases.sql。**当前不把 014 加入线上 migrations、09–13 发布流程或 Worker 初始化。**

## 离线模拟写入 / 双路径读取

scripts/v11-stage-reviewed-sense-aliases.mjs 只允许调用者传入明确的本地 SQLite 连接；正式 Worker 代码没有导入它。

1. 先运行之前已经完成的真实章节语境审核、快照 SHA-256 验证以及旧学习记录影响模拟。
2. 未获人工审核，或多个复习计划冲突、旧学习身份还包含未审核第三张卡时，直接拒绝写入。
3. 仅在本地数据库中对 **两个新增表**做原子插入；同一批准再次运行应保持幂等。若 word_id 已映射到另一 ID 或审核来源不一致，整笔回滚。
4. resolveStagedStudyKey 默认沿用旧 studyKey；只在明确传入 reviewed:true 时读取新增映射表。这是供隔离测试的双路径比较，**不代表读者端已启用**。
5. 不修改已掌握、收藏、复习时间、历史 review_events、已读章节与订单数据；输出只包含映射数量与审校快照摘要，不输出用户原始记录、小说正文或审批证据全文。
