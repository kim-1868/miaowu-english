# 妙屋英语 S3-D0：发布准备预演（只读、禁止实际发布）

## 已确认进度

用户已在 Cloudflare 测试站验收 S1–S3-C1；S3-C2 页面四项检查全部通过，包括检查报告、三项人工复核选项、审核备注及保存入口、历史记录状态与“没有发布按钮”。
**用户尚未证明实际保存一条 C2 审核确认记录，也尚未验证修改正文后该记录失效**。这两项仍需真实浏览器验收。

## 本阶段增加的功能

- 私有 API `GET /api/staging/editor/drafts/:bookId/publication-readiness`，只能在 staging 环境通过 reviewer 门禁 + 独立 S3 编辑 Secret 后使用。
- `/editor.html` 新增「⑦ 上架准备检查 · 尚未开放发布」。
- 读取 S3-C1 自动检查结果、S3-C2 当前版本人工确认记录。
- 明确给出阻断原因：未完成技术检查、无人工审核确认、审核已过期、测试/示例书籍、正式发布功能尚未开启。
- 提醒短篇章数、目标词量及 S3-C1 的其他质量建议。阶段性章节数不是硬性强制 25–35 章，真正上线按已选产品规格人工验收。
- **从未实现、也不提供** POST 发布、下架、修改书籍 status 或修改章节 published_at 的入口。
- 原来的公共阅读接口继续由服务端校验：仅已发布书籍和章节可见；非试看章需要该考试分类有效权益，避免泄露付费小说段落。

## 测试步骤

1. Cloudflare → Workers & Pages → `miaowu-english-staging` → Deployments，确认含 S3-D0 的最新 GitHub 构建为 Ready。
2. 打开 `https://miaowu-english-staging.kim10086a.workers.dev/editor.html`，使用原有管理员 Secret。
3. 打开现有《【示例草稿】未寄出的信》草稿预览，在页面「⑦ 上架准备检查」点击「查看上架准备结果」。
4. 预期展示书名、章节数、目标词数、人工审核状态、不能发布的理由；测试书至少显示 `TEST_MANUSCRIPT` 与 `PUBLICATION_DISABLED`。
5. 如果尚未保存 C2 人工确认，应该有 `MANUAL_REVIEW_REQUIRED`；用户无需为了验收而虚假勾选版权核对，**不要将模拟勾选当作真实审核**。
6. 打开公开读者书架，新导入示例草稿应仍然不可见。普通读者不应取得后台检查报告。

## S3-C2 尚待补验的两项

1. 只对内容确实审核过的部分进行确认，填写明确真实的审核范围，点击“保存本版审核确认（不发布）”。
2. 刷新并重新运行报告，确认显示当前审核有效；修改示例草稿的一个测试句子后再次运行，确认此前记录失效。
3. 请注意：正式商品的原创性、版权归属、英语词汇质量等仍需完整人工复核。可以先不保存，只看发布前预演。

## 后续 S3-D1 正式设计（尚未开发）

- 提供 **单独的正式生产管理员身份**，不能沿用测试站 reviewer 密码或 S3 测试 Secret；

- 发布时原子地更新书籍和章节的可见状态，付费章节继续通过服务器鉴权；

- 区分测试数据与真实商业内容；无正式购买支付链路时绝不当作“可售”。
