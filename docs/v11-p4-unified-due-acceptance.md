# 妙屋英语 V1.1 · P4 复习到期与跨书学习状态验收

状态：开发分支只读状态聚合；不是正式发布报告。对应用户《V1.1 网站与 Agent V2 并行开发执行清单》的 **A 线**，不改 Agent、考研词库或小说内容。

## 问题与修复

旧版读接口在 SQL 中先按单张 user_words 的 status / due_at 筛选，再去重。同义项（跨两本书、不同 wordId）如果旧状态互相矛盾，可能出现「旧卡已掌握但新卡仍出现在今日到期」，导致首页数字、快刷和剧情回声不一致。

本批先列出某账号**已购买或可试读、已正式发布章节**对应的旧词卡，再按 studyKey 聚合。存在 user_study_schedules 时，显式状态/收藏/到期计划覆盖旧投影；尚无 canonical 记录时，任意旧卡明确已掌握则保留掌握，收藏并集保留，最早到期用于未掌握状态。**纯读取聚合，不写 D1，不触碰旧 wordId、阅读进度、订单或已学历史。** 当前 studyKey 仍是兼容候选，尚未升级为有人工证据的词义映射，审核另见 PR #169。

统一接入：首页 `/api/me/words.flashDue`、记忆生词本词卡状态、快刷/听音拼写的 `/api/me/flashcards` 各范围、剧情回声 `/api/me/echo/stats` 与 `/api/me/echo/available?scope=due`。

剧情回声的 due 范围仍以**读完的章节**为题目来源；首页待复习则统计所有已授权、已计划到期义项。因此在尚未完成任何章节时，首页「到期数」可能大于剧情回声「可出题义项数」，属于权限/题目来源规则，不是重复计算。

## 预览站需要站长实测的最短路径

1. 用隔离测试账号兑换测试四级，打开小说 A 一章，点击一个英文目标词并添加生词本；核对「我的书房」与记忆生词本只有一个学习义项。
2. 在快刷中选择「今日到期」或「学习中」练习同一义项，再在小说 B 打开同义词；确认不产生第二张强制新卡；另选同词不同义时应是独立卡。
3. 完成测试章节，进入剧情回声，在有题目来源时用听音拼写或情境题答题；返回首页及快刷，确认到期计数同步。
4. 显式标记「已掌握」后，普通快刷/今日到期/剧情回声 due 不应再出现；主动选「已掌握」范围仍可自愿复习，错题不会自动取消原掌握。
5. 取消「已掌握」或取消收藏时，三个模块同步显示新的显式状态；旧历史掌握不可被新小说的未学习记录覆盖。
6. 切换到没有购买六级的测试账号，六级专属章节词卡不可被快刷、剧情回声题目、首页到期数暴露；另一个账号的记录不得串号。
7. 在 iPhone Safari 与 Android 浏览器分别检查「添加到桌面」教程、朗读主动启停、点击英文词、20 张快刷中的错词4–6张后重现（最多2次）、错题间隔与退出重进。
