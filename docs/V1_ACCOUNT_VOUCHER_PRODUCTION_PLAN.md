# 妙屋英语 V1.0：读者账号 + 兑换码 + Pages 正式环境准备（S12）

更新：2026-11-01。**仅为部署与发行规划，不代表已正式上线或已产生真实订单。**

## 已确定的低成本交付模型

消费者在外部渠道付款 → 商家确认已收款 → 商家从**私有且不可公开**的兑换码库存中分配一枚未使用代码 → 用户在独立的浏览器网站注册/登录 → 输入代码激活对应阅读权限 → 学习进度、词卡收藏和剧情回声记录写入自己的 D1 用户数据。没有应用商店上架的前提要求。正式收费前必须补齐收款、法律与售后条件。

**账号规则（当前代码已具备）**：当前注册 API `/api/auth/register` **必须同时提供一次有效激活码**，所以用户暂时**不能不购买就注册免费账号**。已有账号可在 `/api/activate` 增购不同**分类**的权益。免费试读章节可以匿名阅读，但无权益不能读受限正文。

**务必确认产品授权范围：当前兑换码绑定的是类别 `cet4`、`cet6`、`postgrad`、`ielts`，而不是单本书。** 例如赠送一枚 CET4 分类码，理论上会解锁所有仍有效的 CET4 分类付费章节，包括之后同类上架的新书。这与未来“按本卖小说/单本或合集付费”的商品模型不同。在开始真正发售之前，必须明确是卖“某英语等级全部书”还是“某本书/某套合集”；如果后者，需先扩展书籍级/合集级订单及 entitlement 数据模型，并兼容已存在的分类级授权。**目前不能按单本售价销售类别级代码却宣传只获得一本。**

## 首批生产部署前的保护程序（已开发）

`src/production-surface.js`：当 `APP_ENV=production` 时，用户端访问 `account-test.html`、`reading-test.html`、`editor*.html/.js`、`/api/staging/*`、`/api/chapters/qa-*` 或 `/api/books/qa-*/chapters`，返回 404 且不读取静态文件、数据库；不会影响现有 staging 分支。

`deploy/production.wrangler.jsonc.example`：有意保留 **不可用占位 UUID**，不要直接部署。创建实际全新的生产 D1，并先完成数据库 schema 手工审计/空库基线和备份后，才填写实际配置。本文件没有 Secrets 明文。

运行仅做**只读本地配置核验**的命令：

```bash
node scripts/check-production-config.mjs deploy/production.wrangler.jsonc
```

只有 `APP_ENV=production`、生产 Worker 名称、生产 D1 的**新 UUID**、`assets.run_worker_first=true`、`ACTIVATION_PEPPER` Secret 声明且禁用运营危险开关才会通过。**此脚本通过仍不代表允许上线**：它不读取真实云端 DB 的合法性，也不审核业务功能、用户协议、密码策略或教材。

## 首发交易与用户保障：必须落实

1. **商品边界**：本书/合集/等级分类；免费样章、后续更新是否包含在权益内，明确文字说明。
2. **收款**：先选择具备合规商户收款能力的渠道；用户付款需要订单证据，不能用未确认到账截图替代支付网关回调。
3. **兑换码库存**：正式随机码用离线强随机数与生产 Pepper 的 HMAC，只保存散列到 D1，明码仅在安全库存保存；**同一单据与同一笔款项对应多少兑换码必须可审计**，每个码只能成功兑换一次。现有 `scripts/generate-activation-codes.mjs` 可产生私有库存 CSV + 只含哈希的 SQL，但当前默认不携带订单号及发货状态，必须在正式发售前补齐**订单→兑换码分配→交付**核对台账，避免重复发货或纠纷。
4. **兑换码不可被他人抢兑**：不公开私有库存、不把明码写在公告或聊天记录；发现泄露要有撤销和客户支持流程。
5. **账号恢复**：当前只支持用户名和密码，没有完备的“忘记密码/邮箱验证/安全身份恢复”正式流程。**付费前需要确定账号找回机制**，避免用户换设备、忘密码后丢失可用权益。
6. **售后**：退款、误兑、重复支付、换账号、账号安全；需避免同一订单多次返还权益。
7. **个人信息**：数据最小化、用户隐私政策、账号删除/记录导出、密码存储方案复核、保存期限与访问控制。
8. **正式教材**：目前《雨夜档案》12章为测试草稿，188词仅候选；真实小说故事质量、词汇范围、IPA、音频、原创性未审核。
9. **全国免 VPN 稳定性**：当前用户网络实测 Pages 入口读写已通过；未来自建正式 `pages.dev` 名称及中国移动/电信/联通必须再次验证。
10. **灾备**：独立生产 D1 的 Time Travel/备份、恢复演练、最小权限密钥、事故和充值错误处理，未经审查不得从 staging 直接复制测试账号进入生产。
