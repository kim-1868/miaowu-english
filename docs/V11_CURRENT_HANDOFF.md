## 2. 已开发、已测试的主要 V1.1 工作

1. **阅读与学习入口**：阅读器、记忆藏书票、快速刷词、听音拼写、剧情回声、首页待复习、我的书房等的 V1.1 主要开发与回归测试。
2. **同一兼容义项跨书去重**：当前线上仍基于旧 `studyKey` 的保守兼容身份（英文词目 + 词性 + 中文首义）；同一义项共享学习计划，明显不同词性/义项隔离；维护历史词卡 ID 与学习记录。
3. **跨入口一致性**：书房/首页待复习、词卡、快刷、听音拼写、剧情回声读取规范化复习计划。PR #181 修复规范收藏状态在生词本漏展示；PR #183 修复阅读器显式取消掌握、取消收藏后旧别名状态反弹。
4. **权益安全**：PR #184 使阅读器旧学习别名只从当前有权的已出版/公开试读上下文继承状态，阻止未购、撤销、下架、未发布章节的旧记录误影响合法阅读。
5. **剧情回声跨书到期复习**：PR #185 修复 A 书已学词义、B 书使用另一词卡 ID 时漏掉 B 已完成章节复习题；严格按完整旧身份比对词性/中文教学义项；处理超过 600 处重复标注的分页；权限与已读门槛不变。
6. **真实审核义项的离线技术准备**：PR #177–#180、#181 在**隔离 SQLite** 完成语境指纹、人工审核候选、只读投影及原子写回模拟；新增 `db/014_v11_reviewed_sense_aliases.sql` **未进入当前正式迁移清单、线上未启用**。不得将离线通过当成生产功能已切换。
