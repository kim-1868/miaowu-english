## 4. 小说工厂与正式发布的依赖

小说生产 Agent V2 **仍是独立工作线**，不得将计划或演示包当做已完成售卖内容。用户明确以“小说完成之后，同步更新”为统一正式发布的时机。需完成：

1. 四级等相应品类的原创小说与可导入文件包、封面、书籍标签；按既定目标保障故事自然度和学习密度（常见句内 2–5 个目标词、段落平均 3–6 个；早期跨书重合目标约 30%–40%，约 35%）；后续其他分类依各自词表和审稿结果推进。
2. **先做结构审核，再做人工语义审校**：词义/词性、US/UK IPA、自然例句与搭配、正文语境、重复义项。真实书库历史元数据曾记录 23 本，但并非已核验的实时全库；之前只有 4 本全文曾完成机械核查，不能宣称其他 19 本审校完成。
3. 从小说工厂导入包完成测试环境出版台导入/上架、词卡校验、同义项去重、付费权益及阅读/复习回归；如果需要启用 reviewed 014 映射，必须另行审批、演练与验证，不得默认加入。
4. **小说完成不代表可直接操作正式 D1**。必须完成真实正式 D1 的只读核验、可恢复备份/隔离恢复演练、既有用户学习状态/兑换订单回归、双端真机验收、回滚计划和候选固定 SHA。
5. 正式统一上线顺序建议：冻结小说与 V1.1 候选包 → 公共 UI 差异逐项整合到私人分支 → 隔离预览全链路回归 → 正式 D1 备份/精确增量审查 → 站长确认固定发布版本 → 受控正式部署 → 安全验证、内容上架及逐项验收。具体数据库迁移必须按 release runbook 的依赖关系独立审定，禁止机械照搬顺序。
