# S62｜私有审校台新增混排风险筛选

日期：2026-11-02。

S60 已能在733处语境CSV中标出“动词误入名词位置、形容词缺中心词、混排助词可疑”等启发式风险。本轮把这些**真实标记直接显示到已存在的私有HTML审校台**，让审核人员能在同一个页面从733条里优先找到高风险语境，而非反复滚动全部词句。

**新增内容：**

- 顶部增加“词性混排风险提示”实时条数（从源稿733处检查结果中计算，不写死、不代表错误成立）。
- 在“故事语境”页增加“所有语境／优先看语法风险提示／未触发本类提示”筛选，并与原有章节及关键词搜索联合使用。
- 每条语境含只读 `data-syntax-risk` 标签，筛选使用本地JS，不上传小说或用户数据，不允许一键批准。
- 浏览器中的风险标签**只表示要人工看一眼**：没有触发也不算签审，所有未核准标记仍在原位置显示。

**安全及验收：** 仍只在 `--write-private` 时写入被git忽略的 `private-output/` 离线HTML；默认 `--summary` 没有全文文件。CSP `connect-src 'none'`，没有任何 `fetch` 或表单提交，不接D1。S62测试确认所有733条语境被分成 “有提示/无此类提示”，总数不丢失，188词卡和36题仍全部未审批，发布安全门禁继续阻断。

运行：`node scripts/build-rainy-night-review-dashboard.mjs --write-private`。完成后请在本地用浏览器打开私有HTML文件，不要上传到公开网站或网盘共享链接。

本轮让**真正的原稿审校更容易操作**，但没有伪造一项人工验收签名。
