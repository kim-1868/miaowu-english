## A. 硬阻断项目（全部选中才允许上架）

- [ ] **原创故事完整：** 角色关系、时间线、冲突因果与结局经人工审读；不以特定受版权保护作品为底稿换名改写。
- [ ] **词形/词性正确：** 每个目标词与正文实际语法一致；同形不同义、名词/动词发音分别处理。
- [ ] **主释义正确：** 无 `leak=泄露` 却指屋顶漏水、`power=权力` 却指电源等错义。
- [ ] **发音核验：** 核对 IPA、主重音和英美差异；未核验的词不得标记“通过”。
- [ ] **例句真实自然：** 英文语法自然；中文翻译忠实；例句体现本卡主义项。
- [ ] **常用搭配：** 适用词义有 1–3 条已审真实搭配，或注明为何不适用；不存在以 `[]` 冒充已完成。
- [ ] **中英混排自然：** 不出现 `work室`、`meeting上`、“从系统missing”等机械硬塞。
- [ ] **跨书一义一卡：** 相同义项不产生重复首次学习；不同义项不误合并；不触碰既有用户学习状态。
- [ ] **词卡/章节关联有效：** 所有 `word_id`、chapter/book IDs 和正文链接一致；不存在空格 `segments` 或非法包结构。
- [ ] **阅读与权限：** 分类正确，免费章节默认 0；用测试账号验证阅读、复习、付费权限边界。
- [ ] **数据与版权安全：** 上线文件有审核留痕、合法封面与可恢复版本；生产改动前有新备份。
