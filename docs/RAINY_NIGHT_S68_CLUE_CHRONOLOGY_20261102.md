# S68｜《雨夜档案》第7章线索先后顺序与第12章尾声时间修订

本轮基于真实原稿的章节顺序审阅，修复5处读者能够明显感受到的因果矛盾。**仍为私有草稿，编辑修订不等于正式签审。**

**第7章：**

- 第27段本来已经“走出馆门并收起几周前的签名”，第28段才第一次向老师索要妹妹尚活着的证据、首次出现签名。现改为阅览桌前等待核实可能存在的近期线索，未提前声称已经取得。
- 第32段提前“离开阅览室”，但第33–36段仍然在里面对面谈话、请求转交信件。现改为阅览室内看到一对借书母子，保留对 `responsibility`、`record` 的语境。
- 第34段提前在“回程公交车”上，还提前解释了第37段才读到的姐姐留言“别怪周砚”。现改为阅览桌前梳理问题，不偷跑结局线索。
- 第37段细化为**获准带走的笔录复印件背面**保留手写留言，而不是将含私人数据的原始笔录擅自带出；实际发现时间移至最后，保持悬念。

**第12章：**

- 前文“三个月后书店重新开设了周末朗读活动”“几个月后完成第一批补录”，后文又写“后来书店重新开门迎客”，构成营业时间倒流。现在描述持续正常营业、旧钟不再是需要守候的异常征兆。
