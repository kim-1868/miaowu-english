# S64｜跨章节场景一致性与教学词性精修（2026-11-02）

目标：修正明确可确认的**空间位置矛盾、重复进店、英语动词误作名词**，避免原稿表面上“出现了词”却不值得学习。

本轮在未发布《雨夜档案》正文执行9处局部替换：

- 第2章第3段：信箱一直在书店门外（首章及第三章的线索也指向门外），移除“旧信箱挂在内侧墙上”的冲突。雨中的户外锁孔不再莫名“积着薄灰”，改为锈痕。
- 第5章第4段：第2段已经带照片到达装帧铺，第3段已与店主交流，故第4段改为店铺内部场景，不再重新“沿巷子找到店铺”。
- 第5章另一处：去掉“书脊的 spine”同义复述，改为测量 spine 的宽度和厚度。
- 第6章第12、14段：纠正反射义动词 `reflect` 被误写成名词、被动补语的两处语境；明确“玻璃 reflect 灯光”，并保留影像亮斑不构成身份事实的设定。
- 第8章第1段：`timing` 不是直接等于词条的“排序法”；先核对证据出现的 timing，再按发生顺序排，符合该单词语义。
- 第9章第7段：以安置点为单位记录各自 circumstance，减少生硬的抽象词搭配。
- 第10章第7段：`cooperate` 不直接及物“调查”，改为愿意合作并向调查人员按程序提供材料，区别于无条件恢复对周砚的信任。
