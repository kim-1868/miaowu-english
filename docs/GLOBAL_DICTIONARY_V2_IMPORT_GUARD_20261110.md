# 全局词典 V2 兼容包上传保护（2026-11-10）

新小说 V2 可以不填写 `words[]`，开发分支的离线转换能先生成 V1 兼容审核草稿，但当前 `gdict_...` 是**显示主词条 ID**，并不是对应每个用法的 stable `sense_id`。例如 `record` 名词“记录”与动词“录制”不得共用掌握记录。

为避免错误教程被用户当成正式可用功能，已在 `src/ops-import.js` 的标准 `POST /api/ops/import` 写入流程加入安全检查：
- 普通已有 V1 小说的旧 word ID **完全不变**。
- 凡是包含 `gdict_` 主词条 ID、`v2_tmp_` 暂存 ID，或 `sourceLabel` 为 dictionary-v2 的兼容包，在尚未具备稳定义项学习链路时，写入前以 `DICTIONARY_SENSE_BINDING_REQUIRED` (409) 明确拒绝，防止混同用户学习进度。
- 此保护不会修改已有上线小说、数据库、用户进度或购买权益，且不会自动审核任何教学义项。
- 未来正式解决方案不是移除检查，而是在新的经审批 V2 导入链路直接写入经审核 `sense_id`、旧 word ID 映射和每章节实际语境锚点，确保跨书复习按义项共享、异义项独立。真实 staging D1 013–018 尚未迁移；经过真站完整验收才能开放。

当前仍需原正式四级 23 本和六级 5 本的受控正文版本及 QA，才能进行存量义项匹配和 409 版本化修订。
