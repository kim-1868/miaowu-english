# WordLetter 内部补充词典 · 数据来源与导入要求

## 基本原则

- 目的：在读者点击**例句内**的非目标词时给出英文词典释义参考；不是新建可任意搜索的公共词典。
- 首选妙屋已有有权访问的正式词卡；补充表仅作为缺失时的解释层。返回值设 `referenceOnly: true`，不返回 `wordId`，不自动增加收藏、已学数或复习次数。
- 查询必须提供已授权词卡的 `originWordId`，且所查词必须真实出现在该词卡的英文例句中，不能通过补充表查询未购买小说的例句。
- 仅用于**不破坏用户学习数据**的独立表 `supplemental_dictionary`；创建词卡仍应走正常词义人工审核与去重流程。
- 首批 107 条简单例句词释义为独立整理的 `curated-starter`，不是宣称已有 ECDICT 全库。
- 以后可扩展至更大词典语料，但不能直接将全词典等同于“已掌握”或“应背词汇”。

## 可扩充的数据源

- ECDICT: https://github.com/skywind3000/ECDICT
- 上游 LICENSE: https://github.com/skywind3000/ECDICT/blob/master/LICENSE ，仓库当前公开 MIT 许可，导入时保留完整版权及许可文件；因含聚合词典内容，上线前仍需要确认具体使用条款与来源。
- `python3 scripts/prepare-ecdict-dictionary.py /private/ecdict.csv --out /tmp/mw-dict --limit 12000` 将上游已下载的词库在本地转换为小批量、可审计的 JSON；**此脚本绝不会写入 D1**。
- `manifest.json` 提供原 CSV SHA256、词条数量、批次数、许可证标记。批量导入到**测试库**之前必须先审计来源及反映读者具体需求，并对发音/翻译的合理性抽样。
- 大词典不是本轮 107 条的承诺范围：批量导入需要独立的测试 D1 审核、导入限额、回滚演练和用户预览验收；正式 D1 须单独批准。

## 验收

1. 在书中已收录目标词卡的例句里点击 `suddenly`：若现有词库没有正式义项，显示“突然地；忽然”并标记“内部词典补充 · 仅供理解例句，不计入学习词卡”。
2. 同一个词如果已有有权访问的妙屋正式词卡，则优先显示正式释义和收藏按钮；绝不被后台词典覆盖。
3. 读者无法通过自行拼接 URL 查询未解锁小说的例句或任意生词。
4. 词典查阅不创建 `user_words`、`review_events` 或 `user_study_schedules`；原有复习计数及购买权益不变。
5. 词典未命中时仍允许听发音，并如实告知该词未收录，不能编造释义。

## V1.1 最新交互确认 · 例句点词只发音

考虑到部分词不属于正式学习词库，以及用户反馈“点例句里的词，原本正在学习的词卡消失”，正式采用**例句单词只发音，不打开新词卡、不跳转、不查义项**的交互。

- 小说阅读页：点击目标词打开正式学习词卡；在该卡英文例句中点击其他单词，仅以已有的浏览器 `speakWord()` 播放该词的英文发音。**原词卡保持打开、原高亮状态和学习操作不变**。
- 我的记忆生词本：同样只发音，不打开额外卡片，也不改收藏/掌握状态。
- 剧情回声：仅在答题提交后展示的英文原句及答案中，词汇允许点击发音；题目前禁止点词泄漏答案。
- 后台 `src/internal-dictionary.js` 和独立词典表继续保留作为未来可选择的释义功能数据源，但**当前例句点击不会请求词典**。数据未命中不影响读音。
- 删除不再使用的第二张查询弹层及其样式。当前正式站不变，先在 staging 验收。
