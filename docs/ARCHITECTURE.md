# 妙屋英语 — 技术架构与安全边界

## 产品
- 统一网站展示四级、六级、考研及未来雅思等分类。
- 首发分类：四级。购买四级后解锁其当前已发布的付费内容；后续更新权益暂不确定。
- 自定义用户名 + 首次激活码 + 自设密码完成注册；后续仅用户名 + 密码登录。
- 已登录用户可用新激活码增购其他分类；一个账号累积不同分类权限。
- 手机、平板、电脑共享同一账户进度，采用响应式网页，不要求原生 App。
- 销售倾向小红书自动发独立激活码；正式交易前确认平台商品准入和交付方式。

## 系统组成
- Cloudflare Workers 静态资源与 API（当前仅 /api/health 可用）。
- D1 数据库：用户、分类、小说、章节、词库、激活码、分类购买权益、会话和学习记录。
- UI 设计基准：经确认的 V0.3 原型；本分支暂以安全的开发占位页替代尚未上云的 V0.3 大体积界面素材。

## 安全底线（上线前全部落实）
1. 账号密码不能放在前端 JS 或 localStorage；密码只在服务端做加盐单向派生。
2. 每份激活码为不可预测、一次兑换的凭证；数据库仅存哈希摘要，并防止并发重复兑换。
3. 会话采用 Secure + HttpOnly + SameSite Cookie，服务端鉴权、退出撤销、有效期与限流。
4. 未购付费章节和保护性音频绝不可作为公开静态资源；即使访问者知道 URL 也不能取得正文。
5. 注册、登录、兑换需要统一错误处理、限速、防撞库与 CSRF 保护。
6. 每个学习统计只计真实用户授权可见内容，支持更正、退款撤销与备份恢复。
7. 环境分离（开发/生产），不得在 GitHub 提交密钥、用户密码、真实卡密或个人信息。

此分支为可审查的工程基础，绝不代表完成真实账户或正式上线。
