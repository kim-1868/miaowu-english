# S65｜剧情回声实际题干补全学习提示 + 答案唯一性安全标识

此前36道内部候选题只有长篇原文中挖空，虽然要求“根据语境与中文词义填写”，编辑审校台却**没有把中文义项作为答题提示展示**，而是把它隐藏在答案区域。这会让不熟悉剧情的学习者面对无提示空格，答案可能不唯一。

本轮直接修正从真实12章/188词/733锚点生成的36道剧情回声候选题：

- 新增可见的 `hintZh`：展示本题词卡中文义项的第一个明确释义（保留其他义项在原词卡中供审校）；
- 新增 `firstLetter` 与 `answerLetterCount`：提示首字母和英文字符数量，帮助区分语义近似答案；
- `answerFormat` 明确要求小写目标词原形，避免用户误以为变形词一定应当填入；
- `uniqueAnswerConfirmed:false` 明确警告**首字母和字母数也不能证明答案唯一**。题目的编审人员必须检查在当前中文情境中能否有多个同长度/同首字母替代词。
- 私有离线审校台在题干旁显示上述三种可见提示，答案仍放在编辑专用折叠详情里，36题的未批准提示保持可见。

安全：题目仍是 `EDITORIAL_NOT_APPROVED` 与 `forCloudUse:false`；不把小说上传到 public，不接入云端题库，不启用正式收费，整个词库、锚点数量和发布门禁均不改变。

**限制：** 中文提示来自尚未逐条签审的 `meaningZh` 草稿，不是专业编校结论；后续仍需人工验收释义与可接受答案范围。
