## 可复验的离线工具
新增 scripts/audit-cet4-published-archive-offline.mjs。可使用自己合法导出的当前小说包与原始 CSV：
node scripts/audit-cet4-published-archive-offline.mjs --lexicon /private/owner.csv --novels /private/cet4-published-json --out /private/cet4-match-report.json

可选 --catalog 指向公开书目 JSON，仅做 book ID 比对，不做内容字节对照。工具只读本地 JSON/CSV，输出缺词、词形歧义、正文引用数、孤立卡、中文释义不一致、缺 IPA/例句、零学习目标段落、跨书复现候选。不连接 Cloudflare、不读取用户数据、不动小说/订单/权益，不包含自动发布动作。
