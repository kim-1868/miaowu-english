# 妙屋英语｜独立智能背词安全前置（2026-11-09）

> **只读资料与离线代码预检，非产品功能上线。** 本分支不能直接合并部署，不改现有数据库、原藏书票、阅读记录、快刷词卡、新手引导及购买权益。

## 本轮已确认的事实

1. 现有快刷/听音拼写只接受当前已授权、已发布、且 `user_words.bookmarked=1` 的词义；不能把该池冒充完整的新词池。它的 10/20 张、记忆反馈、独立常用例句、幂等 requestId 均需保留。
2. 小说已有 `user_words` 记录可以是未收藏状态。`bookmark` 与 `learned` 分离；新词推荐必须同时排除已学但未收藏的同义项。
3. 商品等级使用当前有效 `entitlements`；被作废/撤销的权益不可学习该等级。仅前端隐藏不能形成权限控制。
4. 现有 `words` 无词频字段；`word_categories` 挂在书籍导入流程上，不等于已覆盖完整考试词纲。没有经过校验的全量词纲前，不能推出真正完整的词频新词。
5. 现有 `studyKey` 是词目 + 词性 + 主要释义的保守兼容身份，缺字段时回退旧 ID；不可直接凭英文拼写合并不同词义。尚未完成全生产书库人工审稿的 reviewed sense 映射不可擅自开启。
6. 原来的三张注册新手引导 + 首次词卡/收藏提示均存在；**不重做**。新增提示只计划用户首次点击「记忆藏书票」才显示一次，需等真实智能背词入口可用之后一起交付。

## 本次资料核对

用户先前提供的 `考试词表_合并版.md` 是 ECDICT(MIT) 五类标签按 COCA/BNC 语料词频的整合资料，报告全去重 8671 个词目；**语料词频不是四六级真题词频**。来源说明明确 ECDICT 四级 `cet4` 标签约 3849 词、六级 `cet6` 5407 词、考研 `ky` 4801 词、雅思 `ielts` 5040 词（并非均为官方完整大纲），后续需对官方目标清单做覆盖核对并逐义项审校。

读取用户 `postgrad_2026_vocabulary_source.jsonl` 的离线只读统计：6082 行，JSON 解析错误 0，6082 个不重复英文词目；其中 `frequency_available=true` 4966 行，`false` 1116 行。不可把后 1116 行声称为真实真题词频。即使英文头词不重复，也不能据此断言所有音标、释义和例句已经通过商用审校。

## 新增的独立候选选词合同

文件 `src/smart-vocab-preflight.js`：
- 输入仅允许服务端核验过的活跃等级列表；只选所购等级；排除其它级别
- **只有**经审核完备的词库 `catalogVerified=true` 才开启，不作空词库回退到小说词池
- 必须有真实正整数词频名次与明确的 COCA / BNC / POSTGRAD_EXAM 来源；按名次排序
- 单轮最多 20 个不同词义项
- 已学习/已掌握（包括没有收藏）同义项不重复当新词，跨小说同义项同样排除
- 没有足够词性/释义时，不推断同一词义；保守沿用旧 word_id
- 返回字段不包含书名、章节 ID、小说情境原句
- **仅纯函数，无 API、数据库写入、用户操作、生产入口或发布开关**，不构成智能背词已上线

## 后续仍是发布阻断项

- 将经过审核的考试等级词表、准确的词频来源映射为独立词库（不覆盖旧小说 words），校验每一等级的完整性与跨级重叠；缺少可靠考频时 UI 使用「按词表词频优先」，不用「真题高频」宣传
- 新增独立 `GET 新词` + `POST 记得/不记得/收藏` 服务端接口；按权益授权，后台幂等提交，写入 `user_words` / `review_events` 时不要求 `chapter_id` 或收藏
- 让未收藏的智能学习词有到期复习路径；**原快刷词池继续只处理原有已收藏词**，除非后续单独批准调整筛选语义
- 完成相同义项跨小说一致性、不同 POS 不混淆、未购等级/作废授权禁止、提交失败不前进、跨设备同步及无收藏复习回归
- 首次进藏书票的轻提示只在新功能启用后显示，不打断注册三卡、原收藏/阅读提示；老用户不强制重看引导
- 使用独立预览 D1 和受保护测试账号先验收，正式站数据库、运营后台、已发布小说和权限当前一律不动
