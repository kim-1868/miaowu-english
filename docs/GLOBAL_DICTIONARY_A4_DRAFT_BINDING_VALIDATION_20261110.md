# 妙屋英语 · A4 小说自动关联：候选导出、草稿关联与真实来源离线预检（2026-11-10）

关联 [Issue #208](https://github.com/kim-1868/miaowu-english/issues/208)、Draft PR #206。

## A4.1 关联包导出 + 不可篡改校验

- `POST /api/ops/import/bindings/export`：仅在 staging 且 Publisher 角色已验证、已有不可变候选 manifest 时返回**原始小说 JSON + 逐句全词典主词条关联 sidecar**。请求要求真实两枚 SHA256 指纹、保存候选的操作员身份、原小说未入旧版修订流程、全部来源与词卡当前仍获审核。
- 导出不可改变旧 `words[].id` 或 `chapter.segments[].wordId`，并明确 `publication_ready:false`。
- `src/global-dictionary-bundle.js`：独立校验导出包哈希、全量目标词坐标、旧词卡 ID、规范词头身份、同 ID 多词头冲突，拒绝缺失/新增单词和伪造数据。

## A4.2 预览站**新书草稿**与词典主词条独立关联

- `db/015_global_dictionary_book_bindings.sql`：按 `book_id/chapter_id/context_anchor` 保存逐次目标词与字典主词条的对应关系，旧 `chapter_words` 仍完整保留；新增数据库 trigger，阻止已发布书在竞态条件下被绑定。
- `src/global-dictionary-attach.js` + `POST /api/ops/import/bindings/attach`：**三项独立开关**及 Publisher 权限，确认词典索引状态、来源/教学审核与精确指纹、之前保存的候选、操作者、原 JSON 均一致；随后再确认真实 D1 `books/chapters/chapter_words` 的书名、分类、章节、正文、词位置与旧 ID 全部与原包一致。任何漂移、已发布书、未审核词均拒绝。
- 多行 `INSERT` 按每条最多 14 行、98 参数组织成**一个** D1.batch 原子事务；附加失败不会留下部分关联，且不写原有用户学习记录、商品权益和阅读数据。
- 现有 OPS 上传界面：只有在预览环境保存了已审核的关联候选、开关已启用时，「确认上传并上架」变为「上传并关联统一词典（仅保存草稿）」；导入原小说、上传封面、附加 sidecar 后**停止，不自动发布**。未进入该模式的原有上传流程保持不变。
- A4.2 专项测试使用实际 SQLite 的老小说导入计划、独立字典表和 staged manifest，覆盖重复提交、正文/锚点漂移、过期指纹、权限、已发布书阻断和无用户数据写入。
