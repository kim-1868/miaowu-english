## 与前两章连贯

- 第3章《昨天的明天》：进一步解释双重日期可能来自原始纸件、透印和数据导出；与23:47的延时信箱原理互相印证，强调“解释现象”不同于证明寄信人身份。
- 第4章《断电的十一分钟》：将旧账号共用、迁移备份、官方记录与匿名恐吓区分；不能用旧笔名直接指认姐姐。
- 第5章《没有寄件人的地址》：从水印、纤维、缺角、纸张修复追查第47号线索，严格保留来源和隐私边界。
- 第6章《书脊里的回声》：对胶片、照片、反光和第三人身份保持可验证的推断；引向邱老师和后续第7章的见面。

第3–6章扩写沿用已经存在的英文词卡ID与预先规划的剧情线索；既保留对前两章单词的跨章复现，也没有凭空宣称官方CET4词频或准确英美IPA。

## 编辑验收方式

运行 `npm test` 包含 `tests/s28-rainy-night-ch03-ch06-expansion.test.mjs`，核查4章每章3,000–3,500汉字、50–65次英文锚点、全文12章结构、188个候选词、1章免费/11章待授权、以及导入包永远只保持draft。运行 `npm run content:rainy-night-audit` 查看实际跨章词复现、长度和未审核项。

以上篇幅和目标词出现次数只是结构指标，不保证故事自然度和记忆效果。后续需要人工逐句审校中英混排和角色时间轴，不能用 CI 绿灯代替人工文学、词典、版权审核。
