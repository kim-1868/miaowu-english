# S36《雨夜档案》第一季188词编辑分轨方案

本方案**只供内部审校与未来产品文案规划，不自动修改正文、词卡、剧情回声、类别权限或D1数据库**。

来源：用户上传的《全国大学英语四、六级考试大纲（2016年修订版）》PDF，SHA-256 `9166d3c03b7bc43abd9d9df91bd2ef8085b4419286f1e5ca100dea68f3cfd1f1`。详细词形与 PDF 页码见S35审计文件。文件没有提供IPA、词性及中文释义，不能被用于这三类内容的认证。

| 编辑分轨 | 词数 | 作用 |
|---|---:|---|
| `CET4_FORM_CANDIDATE` | 172 | 正文四级核心候选：PDF无星标；其中4个采用打印变体记法，仍需核验义项及词性 |
| `CET6_STORY_EXTENSION` | 9 | 六级拓展词，保留悬疑故事所需的表达，但不计入四级核心词 |
| `MORPHOLOGY_OF_LISTED_ROOT` | 4 | blurred、hidden、childhood、incorrect：配合原词根讲词形变化，不算4个新的大纲独立词目 |
| `STORY_EXTRA_NOT_IN_SYLLABUS_HEADWORDS` | 3 | falsify、outage、watermark：独立词目没有列入2016源词表，但若叙事必要可带中文辅助讲解 |

**审校原则：** 保留剧情自然性比机械将所有出现的英语词标成四级更重要。对外的“四级目标词数”不应超过最终实际完成语义/发音审查并纳入核心轨的词数；暂存172词为候选值，不可称已认证。读者点击这些拓展词仍应获得正确的解释，但学习统计要能区分核心词与扩展词，未来跨小说词库保持可追溯而不混算。

本方案通过 `node scripts/plan-rainy-night-teaching-tracks.mjs --summary` 生成实时分类；校验由 `tests/s36-rainy-night-private-teaching-tracks.test.mjs` 保证所有188词互斥分轨、仍未获发布批准。
