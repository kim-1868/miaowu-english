## 商用上线的实际剩余阻断项
- 7,391 词头所需的逐义项中文释义、实际 IPA/词性、自然**原创**英文例句和中文译文、许可审计、Publisher 正式签核；当前 **approved teaching sense = 0**，尤其不能拿多音词 1,114 项自动当作单一读音。
- 已有历史候选 1,067 条优先审核复用，未有旧内容的 6,550 个词头按原词表 + 小说出现频率分批原创，并明确多义项的 sense ID。相同义项跨书共享，不同义项不混学习状态。
- 先对正式站已上架书做真实最新版本**只读导出**，核对原 book/chapter/word ID、按单词原文位置进行独立词义匹配和差异报告；不直接修改既有书中的卡片。
- 再对 1 本四级 + 1 本六级 + 1 本考研代表小说走真正预览站 OPS V2 自动发现、歧义审核、导入、登录/权益/跨设备测试，然后推广全书架。有关 staging D1 备份、回滚与授权仍必须遵守 [Issue #208](https://github.com/kim-1868/miaowu-english/issues/208) 和 Draft [PR #206](https://github.com/kim-1868/miaowu-english/pull/206)。

**结论：开源候选的实际批量整合已完成；正式可售教学词卡、全书历史映射、生产部署尚未完成，不能以 7,391 词头候选命中率冒充正式词卡覆盖率。**
