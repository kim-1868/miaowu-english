## 推荐测试

1. Cloudflare Worker → Deployments：确认本阶段 GitHub 构建为 Ready。
2. 刷新已创建的 `/editor.html`，输入原有的编辑 Secret。无需新建 Secret，也无需执行 D1 SQL。
3. 在草稿书库中选择《【示例草稿】未寄出的信》，打开草稿预览。
4. 页面底部「⑥ 发布前内容审核」运行检查。
5. 示例原稿可能出现「示例书名」「封面」「只有2个词」「只有一组搭配」等**建议完善**项。这些是合理的，说明审核真实读取草稿而非固定返回通过；你此前修改过 `hesitate` 的释义，报告应从 D1 读取最新数据。
6. 报告如出现红色/阻断问题，应记录错误码并根据实际情况修复；切勿为了通过而随意将测试章节更改为正式商品。
7. 如不想再次改写现有测试数据，只检查报告即可；没有必要创建额外模拟错误。

## 安全与限制

- **当前没有开放正式发布**。后续需先设计并实现带审批和撤回能力的上线机制，并约束真正的生产环境管理员身份、审计、备份。

- 现有读者权益与测试账号不因运行审核而变化。
