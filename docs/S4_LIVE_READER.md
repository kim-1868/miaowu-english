# S4 · 妙屋英语真实云端书房（已完成代码与 CI；待浏览器验收）

## 为什么本次优先做这个

此前用户已实测通过 S3-C2 审核界面和 S3-D0 发布准备检查；但是现有首页仍以 `public/app.js` 内置的示例小说/单词及本地浏览器学习状态为主。单独开放发布开关，并不能保证真实小说、用户学习记录进入可用的前台阅读体验。本次直接打通 Cloudflare D1 → 云端书架 → 阅读 → 收藏/进度。

## 直接访问入口

`https://miaowu-english-staging.kim10086a.workers.dev/live.html`

已有首页 `/` 增加「进入真实云端书房」入口，原型的演示数据仍独立、不与真实账号收藏混用。

已完成：
- `/api/categories` 与 `/api/books?category=...` 获取当前真实已**发布**的分类及书目，未发布草稿永远不显示。
- `/api/books/:bookId/chapters` 显示目录和是否可读。
- `/api/chapters/:id` 读取当前章节，服务端检查未发布、免费试看、已购分类权益；不读取无授权的付费正文。
- `/api/chapters/:id/words` 返回正文词汇标注、音标/释义/例句/搭配；点击英文可以听浏览器发音、收藏、标记掌握。
- `POST /api/me/progress` 和 `GET /api/me/progress`：登录后标记章节已读完，真正写入 D1 的 `reading_progress`，下一次登录仍在。不可写无权读取的付费章节。
- `PUT /api/me/words/:id` 和 `GET /api/me/words`：书签、学习状态（learning/mastered）保存至 D1 的 `user_words`，用户跨设备登录可以读取；不能操作草稿词汇或无分类权限的词汇。
- 主页登录表单、当前账号显示、退出，日夜模式、词义切换、全章朗读（依赖浏览器语音接口）、章节浏览、响应式布局。
- 服务器所有 POST/PUT/PATCH/DELETE 强制同源 Origin，避免已登录会话被跨站发起危险修改。新接口限制 JSON 体大小与参数类型，且需要有效 session。
- 旧测试账号及 CET4/CET6 权益可以直接使用，无需新密钥/新增 D1 表，无需复制 SQL。

## 准确的范围/限制

- 这是与原有视觉原型并行的**真实数据页面**，不是已经替换了原首页全部功能。原首页的「剧情回声」及原型单词仍未接入云端；后续会在这个真实数据层上统一视觉和复习玩法。
- 当前用户导入的《【示例草稿】未寄出的信》仍是草稿，**不能**在读者书架出现。已有 `qa-cet4`/ `qa-cet6` 章节权限测试书目是 staging 已发布的测试书，若它们仍在 D1，可以用来验证云端阅读和保存进度。
- 现有已发布的 QA 测试章节多为纯文字，没有真实词汇标注，因此「收藏词汇」需要等含标注的测试章节由已批准的发布流程上架之后才能从前台点词验证。**不能虚构已存在的词汇内容，也不能将未授权商业正文放到 public/。**
- 当前「已读完」是按点击标记写入进度 1；还没有精确滚动百分比、云端剧情回声/间隔重复、试题记录。
- 目前账号系统仍为 staging 测试版，不能公开收费；Cloudflare reviewer 门禁仍启用，支付未集成。
- 不要为了验证前台直接在 D1 里修改 `books.status` 或 `chapters.published_at`；正式发布/撤回必须走受控的管理逻辑与日志。

## 实际验收（Cloudflare 最新 Build Ready 后）

1. 打开 `/live.html`，应能看到云端分类和已发布的 QA 测试书（若曾经执行过 S2 fixture seed）。
2. 点已发布的 `qa-cet4`，公开试看章节无登录仍能读取；付费章节未授权应显示“请先登录/解锁”，而不是返回正文。
3. 用之前创建的真实测试账号登录（浏览器密码只发往同源 Worker，不传到聊天），测试 CET4 已授权可以打开付费四级章节、无 CET6 授权无法打开付费六级章节。
4. 点击已读完并刷新登录，确认阅读状态仍在（由 D1 保存）。
5. 收藏词汇功能需要未来已发布的带标注章节；可先只检查页面入口，不要把“没有词汇卡”当作权限系统错误。
6. 换浏览器或另一个设备使用同一测试账号，确认进度/词卡状态共享。
7. 如弹出错误，请只发送错误文字/截图，不需要用户密码、激活码或管理员 Secret。
