# S46：正式上架保护——单词音标、词性与例句不可缺失

**目的**：避免某部草稿被改成正式书籍ID并完成运营复核之后，在英美音标、词性或例句仍为空时意外对读者上架。

修改 `src/ops-publication.js` 的发布准备、审批、正式发布三处流程：

- 运营后台 `GET /api/ops/books/:id/readiness` 增加只读 `learningMetadata`，列出实际在本书章节出现的不同单词数量，以及英式IPA、美式IPA、词性、英文例句、中文例句缺失数。即使书中某词出现多次，也只统计一个词条。
- 如果任何单词缺少英式IPA、美式IPA、词性或双语例句，则 `publishAvailable=false`。
- 运营审批 `POST .../approve` 和独立的 `POST .../publish` 都要重新查数据库；资料未齐时返回 `LEARNING_METADATA_INCOMPLETE` (HTTP 409)，而不创建批准记录或发布书籍。
- 原有测试稿/演示稿禁止发布、人工审批指纹、运营双步骤确认、不同权限、数据库事务及已购用户权限仍然保留。
- 这项检查是**完整性校验**，不认证音标是否正确、不认证词义自然度；最终人工编辑/授权检查继续是必要条件。缺少正式版权批准也不能上架。

测试覆盖：缺UK/US任一音标、词性、英中例句各一条；两个词与多处正文标注的去重；已经审批后再被删除音标的竞态；不会改动已存在账号或兑换码。

**特别说明：** 《雨夜档案》当前188个词的UK/US音标仍未人工核准，故不能因为上架保护加强就绕过审核：它仍保持 `draft-`、【测试】、不可出售的状态。用户不需要操作 GitHub 或 Cloudflare。本轮改的是正式运营流程的防错门槛，不写入 D1。
