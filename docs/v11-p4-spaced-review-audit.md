## 已确认并实现的行为

| 项目 | 验收标准 |
|---|---|
| 词义唯一身份 | 同一拼写/词性/主要中文义项共享学习计划；不同义项独立保留 |
| 复习间隔 | 1 → 3 → 7 → 14 → 30 天，30 天封顶 |
| 回忆次数 | 同日多次正确不会无限推迟到期；答错适当提前 |
| 已掌握 | 不因为游戏连胜自动变为“已掌握”；只有用户主动操作更改 |
| 词卡范围 | 默认到期；学习中、我的生词本、全部已学；已掌握独立主动选择 |
| 快刷词卡 | 每轮默认 20 个去重义项；答错后间隔约 4–6 张回炉，最多 2 次 |
| 答题反馈 | 显示结果后主动进入下一题，不自动跳走 |
| 听音拼写 | 先听音、手动输入；正确拼写和中文释义仅在提交后展示 |
| 安全和历史 | 付费词汇必须有对应授权；旧收藏/掌握和答题事件保持；跨小说不拆成相同两张卡 |

## 仍需用户在预览站实测

1. 同一个词在 A 和 B 小说中点击“记得”后不会变成第二张重复卡，但新词性/新义项仍能学习。
2. “快刷词卡”“剧情回声”“听音拼写”提交后，首页/生词本到期数保持一致；同日重复正确不无限递延。
3. 已掌握项不混入默认复习；手动取消已掌握后恢复学习。
4. 手机端词卡、字号、语音、夜间对比；换设备同账号记录应同步。
