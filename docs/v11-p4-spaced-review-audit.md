## 已在分支完成但未接入数据库

1. `src/spaced-review.js`：纯算法，确认阶梯为 1、3、7、14、30 天，区分首次接触和有效反馈，同一天重复正确不无限延长、答错提前、掌握状态不会被练习重置、统一使用北京时间确定学习日。
2. `tests/v11-spaced-review.test.mjs`：覆盖上述算法边界。
3. `public/flashcards.js`：界面层先调整为 20 词、最多两次错词重现、主动下一张以及听音拼写提交前不展示答案词或中文释义。

## 下一步实施门禁

1. **只读数据审计**：对测试库现有 words / user_words / review_events 的重复词义与旧掌握状态评估；不得先改生产 D1。
2. **新增 canonical 表**：独立 user+study_key 计划及迁移映射；对旧 mastered/bookmarked 取保护性汇总，不覆盖历史。
3. **统一事务更新**：快速刷词、剧情回声、听音拼写三种正式答题事件记录不同游戏，但写同一到期计划，幂等防重复。
4. **抽题范围**：今日到期、全部已学、我的生词本、可选已掌握，默认不出现同义项重复卡。
5. **反馈与统计**：主动下一题；首页、书房、三玩法到期计数相等，跨设备和跨小说去重。
6. **测试 D1 验收**：先在 test D1 迁移验证，再 staging 预览，站长亲测；**生产迁移须另行申请最终批准**。

注意：未完成数据迁移前，**不得将上述算法写入现有 D1 老列而破坏用户复习记录**。
