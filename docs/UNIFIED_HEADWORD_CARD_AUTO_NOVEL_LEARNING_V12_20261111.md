# 妙屋英语 V1.2 · 一词一卡 × 小说自动关联 × 点击词卡/朗读 × 词头级间隔复习
日期：2026-11-11。状态：**用户确认的产品设计与后续开发验收规范，尚非已上线功能**。本文件需与 Draft PR #206、Issue #208 及已有 013–018 词典 DB/小说 V2 代码共同使用。

## 一、用户最终确认的使用路径（严格目标）

1. 建立一个**跨四级、六级、考研的统一英文词库**，避免多套冗余词卡。同一个规范词头仅对应一张**可见主词卡**（entry_id），内容包括 n./v./adj. 等常见词性、常用释义、对应英美读音、自然的原创英中例句和适合时的常用搭配。内部仍保留不同已核准的 sense_id 用于精准上下文、例句/发音对应和来源审计，但**不以不同 sense_id 强迫用户背多张卡**。
2. 站长上传带章节和正文的新小说（V2 不要求 words[]），系统逐段自动提取英文 token、识别单词词形/变形，定位已审批词头主卡，并生成章节定位和绑定预览。明确多个可能词头或语境词义未知时，进入审稿/手动确认；缺词/未审词义则呈现待补工作单，**绝不自动制造不真实释义、假批准词卡或借近义词 IPA**。避免把小说中每个英文碎片都不加选择地变成「必学目标词」，区分普通点击查词 vs 教学目标高亮。
3. 已上架小说逐本取得**实际线上最新版**，保留旧 word_id、章节锚点和历史语义；迁移时建立 legacy_word_id → entry_id (+可选 sense_id) 的可审计映射并保留旧用户记录与恢复依据；不能仅凭老快照认为匹配成功。
4. 读者在小说中点击已关联英文词 → **就地显示同一张词头主卡**，优先显示本章使用的义项/发音，仍可查看整张卡的其他词性、例句和搭配；可以主动点击朗读当前单词和例句。用户点词时应暂停小说原有自动朗读，关闭卡后可自行继续；点击词卡外阅读区域可关闭词卡（不误触朗读）；已有手机/桌面弹层方式继续复用。无审批卡不能冒充正式教学卡展示。
5. 读者在 A / B / C 小说遇到同一个规范词头，展示**同一张主卡且同一份用户学习状态**。按 user_id + entry_id 建立单一间隔复习计划；「认识」记录正向反馈而非直接已掌握；「再记一次」缩短到期时间；「标记已掌握」独立操作。**同一天反复点认识不允许无限推迟到期**，跨设备一致，快速刷词与剧情回声共用计划；原玩法成绩/情境反馈各自保存。可记录接触过哪个 sense，但这些信息不自动生成第二条主复习计划。
6. SRS 版本初始周期 1 / 3 / 7 / 14 / 30 天，到期反馈推进，遗忘反馈回退；这一组是产品间隔重复配置，不是宣称个人遗忘曲线精确数值。旧状态归并采用**保守迁移**：一义项 mastered、另一义项 learning 时，词头不能自动算 mastered；旧收藏并集、复习时间不凭空延长、不丢阅读/订单权益。

## 二、已有成果：明确复用，不得从零重建

- ECDICT 400,183 来源**候选**词头和56,898词形关系；7,391考试优先词头来源包、中文和US IPA候选、655条自编英中例句**草稿**、5,985复杂词头分流及92缺US IPA/13中文括号释义风险，全可保留。**原始来源≠已审核可售词卡**。不得擅自引入带未验证授权的英音来源。
- 1,150历史义项候选、2,206旧word_id以及23本历史书快照保留为审稿和迁移参考，不代表线上最新。
- src/global-dictionary-matcher.js、src/global-dictionary-auto-discovery.js、src/global-dictionary-novel-v2.js、src/ops-dictionary-v2.js：已有**只读自动识词与审核候选**以及 V2 无 words[] 的显式学习目标转换，**尚未实现真正自动把全部小说英文 token 标记并生成可点击已审关联**。下一阶段必须补**语境确认→生成绑定锚点→小说渲染/朗读**的受控提交路径。
- db/013–018 已提供主词头、已审义项和旧词ID映射基础；应做**增量** user+entry_id 复习计划/事件映射与后端接口，而非删除意义结构或静默迁移用户记录。
- src/global-dictionary-study-rehearsal.js、src/global-dictionary-sense-study-rehearsal.js 保留为只读状态投影与保守合并基线；必须调整实际用户端以主词头作为学习 key；**不可以仅更换前端标签就宣称跨书SRS已统一**。
- 历史小说阅读词卡/朗读/收藏/快速刷词/剧情回声等交互继续保留并复用，旧用户账号/购买/阅读/复习记录、小说 409 版本化修订语义不能丢。

## 五、不可突破的安全边界
- **不能因为使用同一张主卡，就把同形不同义在小说里的中文注释胡乱匹配。**
- **不能因为旧名词义项 mastered，就在迁移后自动标记整个主词头 mastered。**
- **不能把原始词源与655条草稿直接当成可售内容；未审内容需 fail-closed。**
- **不能未备份就向正式 D1 写库，或以模拟 CI 当作真实线上验收。**
