# 妙屋英语 V1.1 · 多端 UI 自适应专项（P5）

> 范围：首页三列/两列/单列书架、个人书架、阅读器、生词本、快速刷词、剧情回声、账号操作区。只调整布局，不改书籍封面、购买权益或数据结构。
>
> 当前改动仅提交 V1.1 开发分支；发布至预览后才由站长体验验收。正式网站未经授权禁止部署。

## 核心问题与修复

- 原首页封面偏大，文字栏宽度有限；原 `book-actions` 横向 `flex`、按钮 `width:100%`、自适应 `flex-basis` 叠加，在 3 列和窄平板宽度发生按钮文字被迫折行或大小不一。
- 改为封面右侧的**两个满宽、等宽、纵向排列**的 CTA；`继续阅读 →`、`开始阅读 →`、`查看会员目录 →` 以及 `♡ 收藏小说`、`✓ 已收藏` 保持单行。不同书籍卡片不改变点击逻辑，书籍收藏还是原用户状态。
- 601–820px 的窄平板双列书架缩小封面栏比例，为右侧按钮留足宽度；600px 及以下为单列图文卡，窄屏保留封面优先、操作按钮可触达。
- 个人书架两枚操作按钮按可用空间用双列或单列分布，但文字自身不折行。小于 360px 的设备优化卡片封面宽度。
- 其他页面：阅读器工具栏和章节按钮、生词本操作区、剧情回声按钮、闪卡反馈与总结按钮、账号表单及分页按钮统一 `white-space:nowrap` / `min-width:0`；过窄空间由按钮**整项换行或纵向排列**，避免单个按钮标签折为两行。

## 验证矩阵

- 静态回归：`tests/v11-responsive-actions.test.mjs`，校验新样式加载顺序、生产资源白名单、关键 CTA 媒体规则。
- 实际 Chromium 验证：`scripts/test-v11-responsive-browser.mjs`，覆盖宽度 320 / 344 / 360 / 375 / 390 / 430 / 540 / 600 / 601 / 680 / 768 / 820 / 821 / 1024 / 1280 / 1440 / 1920px。
- 测试依据：书卡三种主要动作、收藏状态两种文案、个人书架移除收藏、词卡按钮、剧情回声按钮；检查每个按钮可见、文本只有一行、无按钮横向溢出、无页面横向溢出。浏览器测试使用**本地 HTML 夹具**，不访问生产或测试 D1。
- 页面人工验收仍需检查真实书名、真实封面及日夜模式视觉，包括 Safari/iPhone 字体差异；浏览器本地夹具检查不应被写成所有真实机型的实机认证。

## 阶段边界

完成本阶段后，P5 继续对运营台折叠记录与发码、订单兑换、小说上传审核、发布下架及封面标签进行非破坏性检查；正式 D1 全库词卡质量的只读审计与生产备份恢复核验仍待运行。正式 V1.1 只能在明确获得完整版本上线授权后发布。
