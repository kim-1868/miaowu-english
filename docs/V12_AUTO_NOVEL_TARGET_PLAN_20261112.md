# 新小说上传自动识词 · V1.2 安全目标规划

本批解决原稿仅提供中文故事+未标注英文词时，运营台原有V2模式只识别显式surface/gloss、普通英文仅给非阻塞观察的不足。

新增纯函数 planDraftNovelAutomaticTargets：接受version=2无words[]的新小说草稿、统一词典检索index、可信审核lesson及审核sense清单。对普通文本进行英文分词，排除链接和邮箱，按原段落、原segment和字符偏移返回学习词建议；仅当英文表面词形在词典中匹配唯一、form审核、头词lesson完整、商业来源许可审核以及仅有一个已审核且active的义项时才产生可建议的entry_id + sense_id + 中文含义。多义、未审核、词表外、未许可、变形不确定继续进入pending队列。已有手工标注段落不改变。

没有把临时建议直接转换为可发布novel包，所有建议仅是 PROVISIONAL_UNVERIFIED_CONTEXT。原因：仅凭英文词面唯一无法保证在故事中对应的词义正确，不得把词典释义代入造成错误学习，未获得上下文签核不能启用用户SRS。建议数据可供之后在运营台导入前自动显示，无生产D1查询/写入。最后需要真实上传流程的OPS接线和预览验收。

此外已发布32本的安全已审核sense预览覆盖见V12_PUBLISHED_APPROVED_SENSE_OVERLAY_20261112.md。不处理14本未发布小说。
