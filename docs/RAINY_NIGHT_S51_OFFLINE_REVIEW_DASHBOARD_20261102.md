# S51：《雨夜档案》188词 / 733语境 / 36题离线审校台

2026-11-02。**只用于本地编辑检查，不是读者站功能。**

## 为什么增加这一步

此前188张词卡、733处小说标注以及36道剧情回声候选分别导出为CSV/JSON；审核编辑需要在多个文件间切换。现在将它们组成一个只读、可搜索、可按章节筛选的单页HTML，在桌面浏览器离线查看，便于人工快速比对词义、例句、段落、题目与风险旗标。数据始终保持未批准状态，不能将“看到了候选”误认为“核准”。

## 生成和使用

```bash
node scripts/build-rainy-night-review-dashboard.mjs --summary
node scripts/build-rainy-night-review-dashboard.mjs --write-private
```

第二条命令生成本地的 `private-output/rainy-night-s1-PRIVATE-UNREVIEWED.html`，可直接用浏览器打开。默认只输出统计，不生成HTML。所有生成文件处于 `.gitignore` 的 `private-output/`，**不要上传 GitHub、Cloudflare Pages、邮件公共附件或任何在线文档服务**。

页面提供词卡188条（中英例句、待审来源计数和待审标签）、733处真实段落锚点（章节/词义/原上下文）和36道剧情回声候选（折叠答案）。页面是**纯只读**：没有“已审核”按钮、自动审校、数据存储、浏览器网络请求或上线操作，也不会复制第三方IPA音源。

## 隔离和可靠性

- HTML中所有故事/词卡数据均转义，避免注入执行脚本；无远程CSS/JS；浏览器端仅本地筛选。
- 页面标有“内部草稿·禁止公开”、`0` 正式已审核词与未发布信息。
- 只处理 `draft-` 作品；并强制核对188、733、36等计数以及英美音标尚未批准的真实状态；不符合即失败。
- 测试覆盖完整呈现数、内容转义、拒绝正式ID、无写入模式与受限本地输出目录。
- 该页面**不替代**词性/语义/IPA/版权签审、付费交付及真实D1安全回归。S42发布门禁继续 BLOCKED；不碰生产数据库与用户账号。
