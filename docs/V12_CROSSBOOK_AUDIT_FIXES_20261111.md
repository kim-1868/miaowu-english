# V1.2 · 跨书词卡审核队列核查修复（2026-11-11）

## 本轮检查发现并修复的边界问题

1. **缺词性 / 缺释义旧词卡撞审稿任务 ID**：先前审稿任务以 `headword | pos | meaning` 组成身份，缺失 POS 或 meaning 时同书多条不同旧卡可能相撞，导致整批计划因 `REVIEW_PLAN_TASK_ID_COLLISION` 失败。修复后对身份不完整的候选额外包含经过审计的原始旧词卡 ID；已完整且一致的义项仍聚合为共享候选。**无论何种情况都不自动批准或合并学习状态**。
2. **跨等级未标注词频重复计数**：先前 `unmarked_discovery_queue.occurrences` 是跨所有书的合计，审稿计划以该总数重复填写给四级、六级、考研各自任务。现增加 `occurrences_by_book`，为每级只计算该级所含书籍的真实次数，并验证逐书总和等于全局总数。
3. **损坏或伪造的次数分布**：新增输入守卫，来源缺少逐书次数、次数异常、或总数不一致时拒绝生成任务，避免产生误导性审核优先级。

## 测试范围

- 多个同单词、同中文义项但词性未明确的旧卡，不得生成相同任务 ID 或被误认为同一审核义项；
- 同一个未标注词出现在四级、六级、考研三类书中，分别按该等级自己的次数生成任务；
- 不完整来源、次数总和不一致必须拒绝；
- 原有跨书扫描、小说保密、候选未批准、文稿不改动等测试继续执行。

## 不变的边界

所有数据处理均**离线**。019/020 迁移没有执行，实际在线书架和商业词卡许可也没有经过本轮验收。旧学习进度、购买权限与正式站完全不变。真实审核仍需运营方导出的私密完整快照和授权审核。
