## 自动化完成的内容

运行 `node scripts/review-rainy-night-word-contexts.mjs --summary` 从12章真实草稿构建 **733条语境审核项**。每条项关联稳定的 `chapterId:pXX:sYY` 段落/词段索引、词条ID、当前词性、中文释义、该次词卡gloss、所在段落、前后文、教学分轨（四级候选/六级拓展/词形变化/剧情词）及以下审查风险：

- 英式IPA缺失/多读音，美式 ARPAbet 多读音，词性/词义仍待审；
- **六级拓展词、派生词、剧情辅助词**出现的具体语境，防止错计四级核心；
- 同一词在同一段多次出现、段落总标注超过4次的阅读密度风险；
- 每条都标为 `UNREVIEWED`，可写审稿人、编辑建议和真实审核结论，但不会自动认定已获批准。

`node scripts/review-rainy-night-word-contexts.mjs --write-private` 将完整733条清单保存至本机**被忽略的** `private-output/rainy-night-733-occurrences-UNREVIEWED.csv` 和汇总JSON中。不得将全书带上下文的审核CSV放进 `public/` 或线上可访问URL，以免泄露未上架章节。
