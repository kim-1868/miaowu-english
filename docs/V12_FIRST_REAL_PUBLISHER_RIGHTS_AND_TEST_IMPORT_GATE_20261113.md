## 第1步：必须取得的7项权利来源（逐项保存证据）

1. 中文词义、释义和翻译：来源、权利人、可商用依据。
2. 英式IPA：原始数据版权及改编许可；不可自动将GPL衍生英式IPA当MIT数据。
3. 美式IPA：来源版本、使用权及归属（MIT来源可作候选，具体字段仍需审）。
4. 英文教学例句：本产品原创记录、独立授权或明确公共领域权利。
5. 中文教学例句：单独创作/翻译权与商业传播依据。
6. 搭配：来源及使用权。
7. 小说原文片段：权利归属与用作收费词卡教学的权利。

额外10项独立内容审核：跨书同一**具体语义**、词性、英式音标、美式音标、英文例句、中文例句、情节语境、商用许可、已有统一词典词条身份、OPS正式签核。

每项证据应记录权利人、授权基础（原创/授权/公有领域）、具体凭证位置与SHA256、审核人员、时间。原英文单词/中文译意相似不能代替审稿或授权。新统一词典lesson可使用独立创作、已审校的双语教学例句，**不必复制旧小说词卡的未核权利例句**；但必须保持原小说旧卡/正文不变并校验其SHA。
