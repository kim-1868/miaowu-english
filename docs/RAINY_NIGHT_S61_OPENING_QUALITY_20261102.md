# S61｜首两章试读关键句自然度 + 悬疑证据推理核查（仍为内部草稿）

日期：2026-11-02。

针对《雨夜档案》最容易影响读者留存的**第1–2章**，从真实正文重新检查三个维度：英文单词融入中文句子的自然度、单词实际教学义项、人物能否凭现有证据作出某项推断。

实际修订：

1. 第1章·第5段：将笼统的“记忆再 familiar 也未必 confirm 得了事实”改成“证人描述听起来 familiar，也不足以 confirm 姐姐的行踪”，避免把“熟悉”直接当作可确认事实的证据。
2. 第1章·第8段：移除“familiar 感”的机械中英后缀，改为“字迹看起来格外 familiar”。
3. 第1章·第23段：不再让主人公“认出自己姐姐的名字”这种没有信息价值的显然动作，改为识别出男人问话正符合姐姐留下的防备警告。
4. 第1章·第30段：修改口语确认问题的双重疑问句，让 `confirm` 成为自然动作。
5. 第2章·第28段：不再无根据断言“停电十一分钟的空白必定留下另一份记录”；让主人公先找原始纸质登记来交叉核实。
6. 第2章·第32段：不再把照片分开保管直接判定为“故意”；明确其原本在两个 `separate` 文件袋中，但原因尚待核查。

这6处修改不添加新人物、不改变12章结构、188词、733处锚点和36道内部题候选，也不自动认定全文已通过编辑。新的S61回归测试阻止旧句式和没有证据的因果断言重新出现。书籍仍是 `draft-`，音标、词义、原创性、支付及商业安全发布门禁继续阻断。
