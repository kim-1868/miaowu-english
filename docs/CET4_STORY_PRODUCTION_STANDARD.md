# 妙屋英语｜CET-4 小说词汇覆盖与跨书重复率生产标准

**标准状态：已确认（2026-11-05）**  
**适用范围：** 后续所有 CET-4 原创小说的选词、创作、编辑、审核、导入前检查，以及未来小说生产 Agent。此规则覆盖旧版文件中“每本约 200 词、旧词约 50 个（25%）”的历史规划占比；不代表现有作品已经全部符合标准。

## 1. 核心原则（必须执行）

**四级词库尚在扩充阶段时，新小说的“跨书重复率”以 35% 为目标值，允许 30%–40% 浮动；其余 60%–70% 应为已上架四级书架尚未覆盖的新目标词。**

- 生产默认：先完成一部独立好读、情节连贯的原创小说，再将待覆盖词合理融入情节；不可为凑词量而造成不自然表达。
- 新词优先：当前阶段一本书不能只重复书架已有词，应带来实质性新词覆盖。
- 复现保留：30%–40% 的跨书重复不是浪费，应优先选择对记忆有价值、适合新情境且需要巩固的核心词。
- **“跨书重复率”只用于不同小说之间；一本小说内部的自然复现另算，不应与跨书重复率混淆。**
- 同一个英文词在不同语境中的词性、义项需由编辑复核，不能为了去重而错误合并词义或错误判定四级资格。

## 2. 计算定义与数据口径

在拟上架四级新书完成草稿、明确候选目标词后：

1. `N`＝新书所有章节中出现过的、已经校对并归一的不同目标词目数（同书多次出现只算一个）。
2. `R`＝其中在**当前已发布的 CET-4 书架**任一本小说里也出现过的归一目标词目数。
3. `A`＝`N-R`，即新书给整个四级书架带来的新增覆盖词目数。

- **跨书重复率＝`R / N × 100%`。**
- **新词占比＝`A / N × 100%`。**
- 例如新书有 160 个不同目标词，56 个与书架重合、104 个首次覆盖，则跨书重复率为 35%，新词占比为 65%。
- 按 `headword`/归一词目（必要时按经审核义项）判断是否重合，**不得只对比 `words.id`**。当前线上多个小说把相同英文词分配了不同 ID，直接按 ID 比较会错误得出 0% 重复。
- 统一大小写、Unicode 规范化；常见屈折变形须映射回经审核词形；派生词、不同词性和不同义项需要按词库既定规则人工审定。不要把未审核的词计入“已核验四级覆盖”。
- 排除未发布草稿、其他等级书架、测试词卡和纯正文中未绑定的普通英文。**对于暂未完成等级核验的候选词，同时报告“候选词重复率”和“已核验四级词重复率”，不得混写。**

## 3. 分阶段的滚动标准

| 阶段 | 新书跨书重复率 | 新增词占比 | 编辑目标 |
|---|---:|---:|---|
| **现阶段：扩充初始四级词库** | **30%–40%（优先 35%）** | **60%–70%** | 每新增一书都实质扩充四级覆盖 |
| 中期：已核验覆盖约 2,000 个词目 | 建议 40%–50% | 50%–60% | 扩词与巩固并重 |
| 后期：已核验核心词库接近目标覆盖 | 建议 50%–70% | 30%–50% | 用新剧情和新义项巩固已学词 |

- **切换阶段依据“跨所有已出版小说去重、经过正式等级来源核验的实际四级覆盖量”决定，而不是小说本数、总词卡数或累计正文标注次数。**
- “约 4,500 词”目前是四级产品的长期规划容量，不是已确定的现行官方精确词表规模。正式阶段阈值需参照审核通过的词源版本持续校准。
- 无论哪一阶段，不能因为数字指标牺牲剧情自然度和语义正确性。

## 4. 单本小说内部复现的独立要求

- 核心目标词可优先设计在**不同章节或不同情节中自然复现约 3–6 次**，作为编辑参考而非每词强制计数；场景边缘词可较少。
- 尽量在有意义的行为、对话和剧情推进中复现，不靠相邻句机械重复。
- 正文的中英混排密度、发音、词义、例句、词性、版权与故事审查继续遵照已有专项标准；跨书重复率合格不代表其他质量审核自动合格。

## 5. 新小说上架前的必备审计项目

每本四级新书的审核报告应提供：

| 指标 | 验收要求 |
|---|---|
| 新书独立目标词目数 `N` | 明确数值、按全文归一去重 |
| 与已上架四级小说重合的词目 `R` | 逐词可追踪书籍、按归一头词/义项比较 |
| 新引入的四级目标词目 `A` | `N-R`，与词表明细可核对 |
| **跨书重复率 `R/N`** | **当前 30%–40%，优先 35%** |
| 新词占比 `A/N` | 当前 60%–70% |
| 重复词质量 | 多义项、词性、词卡质量及自然复现审校 |
| 已核验 CET-4 词源 | 标明词库版本、已审词数量、待审核候选数量 |
| 书架累计词目覆盖变化 | 记录出版前、出版后全书架去重数量；勿把同词不同 ID 算成新覆盖 |

处理规则：

1. 在选词计划阶段先校验一次；全文定稿或词卡调整后，**上架前再次统计**，避免修改正文导致指标漂移。
2. 当前阶段 **高于 40%**：原则上返工选词或扩充自然剧情引入新词；特殊题材需人工说明理由、明确批准。
3. 当前阶段 **低于 30%**：评估是否缺少必要的跨书复现；必要时加入适合剧情的巩固词，不为指标硬塞。
4. 达标后还必须检查词卡质量、故事完整性、四级词源、可读性和付费权限。
5. 审计工具尚未接入运营后台自动阻断：**本标准是即刻生效的编辑验收要求，不得误称已经上线自动检测/自动拦截功能。**

## 6. 读者学习状态配套要求（另行开发验收）

- 对跨书相同词目且同一审核义项，用户学习状态应全站共享，不得因换书重新成为未学词；对新增义项可单独组织学习。
- 保留每本小说不同的剧情原句与点击解释，使“语境再次遇见”可以存在，但避免重复收藏、重复计算已掌握数量及无意义重复推送。
- 任何 ID 关联与学习状态合并均需独立方案、回滚准备及历史数据保护；**本文件不执行数据库迁移**。

## 7. 基线与数据解释（2026-11-05 只读审计）

- 线上 CET-4 书架：17 本已发布作品、124 章。
- 按英文归一头词去重：564 个不同的 CET-4 标记词目（**不等于都已通过官方等级来源复核**）。
- 各书独立词目加总 1,437；全书架去重 564；由此得到历史累计跨书冗余率约 60.75%。
- 另有 273 个头词至少出现在两本书。这些词当前在不同书中全部使用不同的 `word_id`，需要另行治理读者状态一致性。
- **60.75% 是“历史全书架累计冗余率”，而 30%–40% 是“每一本新增小说相对出版前书架的重复率”，两者定义不同，不可直接比较或强行将历史累计值压至 35%。**

## 读者端强制标准：同义只学一张词卡（V35）

**最高优先级。** “不同小说重复出现目标英文单词”与“读者被要求重复学习相同义项”是两回事，必须严格区分：

1. 小说 A 中对词义点击 **「记得」** 后，系统记住这次学习，小说 B 的同词性、同义项**不再计入本章未学新词，也不再要求重新完成首次学习**；“记得”只是已学过，不等同永久掌握。
2. 小说 B 的英文原词、词义、发音、故事原句继续显示；读者**自愿**点击才能再次复习已学词。
3. 一个用户在「记忆藏书票」中，对相同义项**最多看到一张卡**；今日待复习、快刷词卡和已掌握统计也按义项去重，保留正常的间隔复习。
4. 相同拼写但**不同词性或真正不同的义项**可以分别建卡，例如 `record / n. 记录` 与 `record / v. 录制`。
5. 现有发布小说、章节内嵌原词卡 ID、用户原始复习事件不强制改写，不破坏账号、销售权益与阅读进度。
6. 新书导入时必须尽可能复用已有审核词义身份；遇到多义、词性不清或混合词义卡，进入义项审校，**不得仅按英文拼写强行合并**。

**V35 快速兼容实现说明：** 由于线上历史词卡跨小说没有共享 ID，先采用英文归一词目 + 词性 + **第一中文教学释义**判断明显相同的教学义项；只同步用户可阅读的已发布词卡记录，书籍和原旧 ID 不动。中文其他义项、混合词性、释义措辞不同的复杂情形尚需编辑审校和最终统一 `sense_id`，不能宣称所有历史多义词已经完成语义审核。相关处理代码：`src/study-identity.js`、`src/reading-library.js`、`src/echo-cloud.js`、`src/worker.js`。

验收：同义的 A/B 书在 A 点「记得」后，B 本章速记不再出此卡；藏书票只出现一张；新词性/新义项不被误识别为学过；同用户不同设备能同步；没权限的用户不读取付费内容。

## 8. 与既有文档的优先级

本标准由用户于 **2026-11-05 确认**，作为 CET-4 新小说生产和审核的现行要求；涉及**新书跨书重复率**的条款优先于 `docs/V1_CET4_MULTI_NOVEL_CURRICULUM.md` 旧版容量推演、旧复现比例，以及其他较早日期草稿中的建议值。其他不冲突的剧情、语言、密度与运营安全规范仍有效。
