# S70｜修补审稿签名与词典、音标许可和考纲来源的版本绑定

发现 S66 原有人工审校记录中，词卡指纹只包括英文目标词、少数音标候选及部分来源SHA；**没有包含完整的英国音标补缺来源URL/商用授权状态、美国ARPAbet候选、美国IPA多个候选、完整官方2016考纲分级行**。即使正文未改，来源许可和考试级别的待审核材料变动，也可能导致旧“审核通过”仍显示有效。

本轮采用**失效优先**修复：

- 188张词卡各自的 `sourceHash` 现在绑定整个 `createVocabularyReviewQueue` 源数据条目，而不是人工抽取的少量属性；包括英式IPA来源、7项补缺引用、引用URL与是否商业许可、美式ARPAbet、美式IPA不同读音候选、例句、词性及未审批旗标。
- 同时绑定2016年官方考纲的**逐词形式核对结果**，其PDF源文件SHA、审核状态与词条自身的PDF页码/加星情况；所有正式等级和义项仍保持未批准。
- 绑定来源SHA与许可声明，使此后修改词典素材、来源元数据、考纲核对结果或版权状态时，**以前生成的人工审稿JSON被视为旧版，不能沿用原签名**。
- 188词卡+733真实语境+36练习总957条不变，审校台/JSON接口不改变操作方式；从本轮版本生成新审核文件，既有原稿旧版JSON应通过验证失败并重新核对，不能自动搬运历史“通过”。
- 新增测试基于全部188个实际源词卡重算指纹，并模拟`blurred`缺失英音候选的授权、来源URL、美式读音与考纲状态变动，验证任何一项都不能被误认为同版来源。

**这只提高人工审校证据可信度，不解决音标版权本身、不代表所有词卡已人工核实、不解除 `BLOCKED`，不公开草稿或修改正式D1。**
