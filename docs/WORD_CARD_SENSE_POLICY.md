# 妙屋英语词卡义项规范

- 正文标注绑定当前实际用到的词性和义项。主卡显示本句词义，音标、例句、译文和搭配均按这个义项审核。
- 其他常见义项可在主卡下折叠展示。补充内容只用于查阅，标明词性、释义和有区别的发音。首批覆盖 list、notice、record。历史混标卡无法明确识别当前义项时，保留原显示，交内容审校处理。
- 收藏、掌握、复习等操作仍绑定当前卡片的已有学习身份。跨书共享沿用 P5 审核流程。仅凭拼写或释义文字相似不能自动合并。保留历史 wordId 和读者学习记录。
- 正式发布前复测手机与桌面阅读器。展开其他义项后，收藏和掌握仍应作用于当前卡。切换词卡后折叠区应随卡片重新渲染。使用已有受控生产发布流程，保留公告构建及现有生产绑定。
