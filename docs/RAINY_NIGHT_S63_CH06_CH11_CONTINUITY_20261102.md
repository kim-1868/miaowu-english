# S63｜《雨夜档案》真实剧情连续性修订：第6章与第11章

状态：未批准的私有编辑稿；没有 Cloudflare D1 或正式用户数据变更，也没有解除出版门禁。

本轮比局部句式润色更进一步，处理影响悬疑可信度的**时间线和重复情节**：

**第6章（8个段落修订）：**
- 原本第1段已经拆书并发现索引页和照片，第4、5、6段却退回到“装帧店没开门”“店主还没取书”“准备打开书脊”，构成时间倒流。
- 现在第1至3段只整理先前从周砚与短信获得的既有照片，尝试负片显示；第4段在装帧铺开门前整理材料；第5、6段完成权限说明与拆书准备；第7段才真正打开书脊、发现索引页背后的新增照片；第8段再在数字副本中放大局部。**没有凭图像放大凭空创造细节，也没有把拍摄地点相似误认为照片同日拍摄。**
- 章节尾声原本第35段和第37段分别记了一次“与邱老师首次通话”，第31段与第36段也重复收到同一木箱消息。现在把第35–37段改为同一次电话的开端、核对已收到的图书馆邮件、结尾悬念；邮件只发生一次且附合法查阅条件。保留全部目标词锚点。

**第11章（1段修订）：**
- 原第1段已经开箱看到账册，第3段却称“预约开始前”且断言封条仍完整。这会误导读者认为开箱前后的封条是同一状态。
- 改为翻阅账册期间核对**刚拆下并妥善保留**的封存条及封存编号；强调封存编号可追溯并不能证实数字内容准确。

**第7章（1处句式修订）：**
- “一条 recent 的线索”简化为“一条 recent 线索”，排除自动句法风险提示里一个可明确调整的助词问题。
